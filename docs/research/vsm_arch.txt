TOPIC: UE5 Virtual Shadow Maps — core architecture & data structures

FRAME FLOW:
Per frame (BuildPageAllocations pass chain, VirtualShadowMapArray.cpp ~2800-3500): (0) ClearPageTable/flags + InitPageRectBounds (reset rect bounds to empty, reset 4 page-list counters). (1) PruneLightGrid — copy of the clustered light grid keeping only VSM-bearing lights, distant lights sorted last. (2) MarkCoarsePages + GeneratePageFlagsFromPixels (one thread/screen pixel, from scene depth + optional water/translucency/hair depth) [+ optional GeneratePageFlagsFromFroxels] -> writes PageRequestFlags (+ receiver masks). (3) PropagateFilterableRequests (secondary requests for prefiltered-distant fallback). (4) UpdatePhysicalPages — walk physical pages in last-frame LRU order; keep re-requested/young pages (apply invalidations -> page flags + PT entry), push kept->REQUESTED, dead->EMPTY. (5) PackAvailablePages — compact surviving LRU entries + append EMPTY into AVAILABLE. (6) AllocateNewPageMappings — for each requested-but-unmapped PT entry, pop AVAILABLE (stealing victims' PT entries as needed), write PT + flags + metadata. (7) GenerateHierarchicalPageFlags — OR flags up the HMip pyramid, build Allocated/Uncached page rect bounds per (VSM,mip). (8) PropagateMappedMips — fill unmapped PT entries with coarser-LOD pointers (mips for locals, coarser clipmap levels for directional). (9) SelectPagesToInitialize + InitializePhysicalPagesIndirect — clear (or static-copy) exactly the pages to be rendered. (10) Render casters: Nanite passes + non-Nanite CullPerPageDrawCommands -> AllocateCommandInstanceOutputSpace -> OutputCommandInstanceLists -> Rasterize per mip/clipmap view (PS does virtual->physical translation + InterlockedMax depth). (11) MergeStaticPhysicalPagesIndirect (static slice -> dynamic slice for pages where both exist). (12) SelectPagesForHZB + BuildHZBPerPage(Top) — per-page min-depth pyramid for next frame's caster occlusion. (13) Projection/sampling passes read PageTable + PhysicalPagePool via ShadowVirtualToPhysicalUV (one PT read thanks to step 8). (14) AppendPhysicalPageLists — REQUESTED becomes next frame's LRU seed. Between frames, GPU invalidation passes (moving primitives) set INVALIDATE_DYNAMIC/STATIC on physical page metadata consumed in step 4.

DREAMCOAST NOTES:
Adaptation guidance for DreamCoast (single directional sun + point lights, no Nanite, bindless, render-graph): (1) The whole system is ~12 compute passes + your existing shadow raster path; nothing requires Nanite — UE's non-Nanite path (BuildPerPageDrawCommands + PS with InterlockedMax into an R32_UINT pool) is exactly the no-Nanite architecture, and it maps cleanly onto DreamCoast's existing GPU culling (cull.rs) as an extra per-mip-view cull with a hierarchical page-flag test. R32_UINT + atomic max works identically on VK/DX12 (Metal needs the same texture-atomic support you already use elsewhere or a buffer-backed pool). (2) Sizing for one sun: N clipmap levels (say 8-16 levels vs UE's 6..22) x 1 VSM each, plus one 8-mip VSM per point-light face; a 1024-2048 page pool (64-128MB single slice) is UE's shipping default. If you skip the static/dynamic split cache initially, the pool is ONE slice and you can drop merge/init-copy passes — but then every requested page re-renders when anything moves; UE's split is its main perf lever, so keep the two-slice design in mind (it fits the memory notes' no-freeze directive: cached pages with explicit invalidation, not convergence latches). (3) The three most load-bearing ideas to copy faithfully: per-pixel page marking from the depth buffer with analytic clipmap-level selection (log2 distance) — trivially cheap, one pass over the G-buffer you already have; the 32-bit PT entry with LODOffset + PropagateMappedMips so sampling is a single fetch with automatic coarse fallback (no feedback loop, no fault handling); and the OR'd hierarchical page-flag pyramid + per-mip uncached page rect for culling casters. (4) The LRU 4-list scheme is subtle (order preservation across frames via the REQUESTED list) but small; a simpler first cut is age-based eviction using LastRequestedSceneFrameNumber only, upgrading to list-order LRU later. (5) Receiver masks, froxel marking, prefiltered-distant, throttling, first-person flags, and single-page distant lights are all optional layers — for a dungeon crawler with few point lights, skip single-page SMs entirely and give every light full VSMs. (6) Watch cross-backend parity: all state lives in uint textures/buffers written with atomics, so determinism is good, but the PS depth atomic ordering makes raster output bit-stable only per-texel (max is commutative) — VK/DX12 parity should hold to your 0.001 bar. (7) UE marks requests with plain (non-atomic) stores of identical values and relies on idempotence — fine under both APIs' memory models for same-value races, but your validation layers may flag it; InterlockedOr is the safe equivalent.

MECHANISMS:

## Virtual address space & page table layout
Every VSM (each clipmap level and each local-light cube face/spot map is its own VSM with its own VirtualShadowMapId) is a 16384x16384 virtual texture = 128x128 pages of 128x128 texels, with a full mip chain of 8 levels (each mip halves page count down to 1x1). The page table for ALL VSMs lives in one big R32_UINT 2D texture: each full VSM gets a 128x192 texel block (128x128 level-0 grid plus a mip tail laid out below it: CalcLevelOffsets puts mip>0 at y+=128 with x offset packed via bitmask trick so all 7 tail mips fit in a 128x64 strip). Blocks are tiled in rows across the texture (PageTableRowShift/RowMask select the block from the shadow-map ID). Single-page (distant) VSMs don't get a block; their single entry is packed by ID into the first 128x128 region (ID%128, ID/128). Virtual UV -> page: vPage = uint2(UV * 128) >> mip; entry address = block origin + CalcLevelOffsets(mip) + vPage. Physical texel = entry.PhysicalAddress*128 + (virtualTexel & 127).
[refs] Engine/Shaders/Shared/VirtualShadowMapDefinitions.h:13-38 (VSM_LOG2_PAGE_SIZE=7, VSM_LOG2_LEVEL0_DIM_PAGES_XY=7, VSM_MAX_MIP_LEVELS=8, VSM_PAGE_TABLE_TEX2D_SIZE=128x192); VirtualShadowMapPageAccessCommon.ush:87-100 (CalcLevelOffsets), 127-147 (CalcPageTableLevelOffset), 305-371 (VirtualToPhysicalTexel / ShadowVirtualToPhysicalUV); VirtualShadowMapArray.h:70-87

## Page table entry encoding (32-bit)
PT entry: bits [0:9] physical page X, [10:19] physical page Y, [20:25] LODOffset (how many levels coarser the actually-mapped page is), [29] bIsSecondaryRequest, [30] bThisLODValidForRendering, [31] bAnyLODValid. A page mapped exactly at this level has LODOffset=0 and the VALID_FOR_RENDERING flag; entries filled in by mip-propagation point at a coarser page's physical address with LODOffset>0 and are valid for sampling fallback but never for rendering. Sampling reads ONE page-table texel at MinMipLevel and immediately knows both the physical address and which LOD it actually got — no page-fault loop.
[refs] VirtualShadowMapPageAccessCommon.ush:237-287 (FShadowPhysicalPage, ShadowEncodePageTable/ShadowDecodePageTable)

## Physical page pool
One Texture2DArray<uint> (PF_R32_UINT, atomic-capable). Width is fixed at max-2D-texture width (16384 -> 128 pages/row, power of two so index<->x,y is mask+shift via PhysicalPageRowMask/Shift); height = ceil(MaxPhysicalPages / pagesPerRow) * 128. r.Shadow.Virtual.MaxPhysicalPages default 2048 (= 2048*128*128*4B = 128MB per slice). Array slice 0 = dynamic pages, slice 1 = static-cached pages when caching enabled (StaticCachedArrayIndex=1) — every allocation is implicitly a pair at the same x,y in both slices; slice 3 only for debug visualization. Depth is stored as asuint(float) and written with InterlockedMax (reverse-Z max = nearest wins... actually furthest-from-light occluder logic via max of device Z). Optionally created as a reserved/tiled resource for better VidMM paging. A parallel FPhysicalPageMetaData structured buffer (Flags, LastRequestedSceneFrameNumber, VirtualShadowMapId, MipLevel, PageAddress) is the reverse mapping physical->virtual.
[refs] VirtualShadowMapArray.cpp:174-180 (CVar, default 2048), 1006-1044 (pool sizing, RowMask/Shift), 2420-2429 (PoolArraySize=2, HZB pool); VirtualShadowMapCacheManager.cpp:1090-1125 (PF_R32_UINT, reserved resource); Definitions.h:147-155 (FPhysicalPageMetaData); ShadowDepthPixelShader.usf:103 (InterlockedMax depth write)

## Page marking from screen pixels (the demand signal)
GeneratePageFlagsFromPixels: one compute thread per screen pixel (8x8 groups; permutations for GBuffer, GBuffer+water depth, front-layer translucency depth, hair). For each valid pixel: reconstruct translated-world position from depth. For every directional VSM: compute the desired clipmap level analytically from distance (CalcAbsoluteClipmapLevel + resolution LOD biases, floor -> which clipmap level VSM), project into that level's UV, and write VSM_FLAG_ALLOCATED|DETAIL_GEOMETRY|PRIMARY_REQUEST into the PageRequestFlags texture at that page entry (plain store, no atomic needed — flags idempotent). For local lights: iterate the (pruned) light grid cell for that pixel, select cube face from direction, compute mip = log2(pixel footprint in shadow space) clamped to [0,7] (GetMipLevelLocal; MipModeLocal can force even/odd-only mips to halve instance duplication), mark that page. Page dilation: if the pixel lands within 5% (PageDilationBorderSize*, default 0.05) of a page border, also mark one diagonal neighbor chosen by a 2x2 dither on thread index — cheap insurance against edge misses. Optional backface-to-light culling of requests. A separate froxel-based path (GeneratePageFlagsFromFroxelsCS) marks pages from view froxels instead of exact pixels. MarkCoarsePages additionally: for directional coarse clip levels (>= r.Shadow.Virtual.Clipmap.FirstCoarseLevel, default 15) marks the 2x2 pages around the clipmap origin (for fog/translucency consumers); for local lights marks the last mip (1 page) always for single-page distant lights and optionally for all locals. Requests are per-frame; nothing persists in the request texture.
[refs] VirtualShadowMapPageMarking.usf:319-615 (GeneratePageFlagsFromPixels), 646+ (froxels), 799-873 (MarkCoarsePages); VirtualShadowMapPageMarking.ush:82-174 (MarkPage/MarkPageDirectional/MarkPageLocal, dilation); VirtualShadowMapArray.cpp:370-434 (dilation/marking CVars); Definitions.h:178-196 (GetMipLevelLocal)

## Physical page lifecycle: cache-aware LRU allocation
PhysicalPageLists buffer = 4 lists, each MaxPhysicalPages ints + a count: LRU, AVAILABLE, EMPTY, REQUESTED. Per frame: (1) InitPageRectBounds resets counts (LRU starts 'full'). (2) UpdatePhysicalPages — one thread per physical page, iterated in LAST frame's REQUESTED-list order (which preserves LRU ordering across frames when r.Shadow.Virtual.Cache.AllocateViaLRU=1): looks up whether the page's virtual slot was requested again this frame (reads PageRequestFlags via the metadata back-pointer). If requested (or light unreferenced, or age <= r.Shadow.Virtual.Cache.MaxPageAgeSinceLastRequest, default 1000 frames): keep it — push to REQUESTED, re-write its PT entry + page flags (applying any invalidation flags accumulated on the physical metadata: dynamic-only vs full uncache, deferred-invalidation budget, receiver-mask forced dynamic uncache); if a cached page's aux flags (detail-geometry etc.) changed, treat as full invalidation. Not-kept pages go to EMPTY; kept-but-not-requested pages stay in the LRU list slot (others written as INDEX_NONE). (3) PackAvailablePages compacts LRU (minus removed) into AVAILABLE, then appends EMPTY — so allocation pops least-recently-used cached pages LAST... (allocations come from the end: empty/invalidated pages first, then most-stale cached pages). (4) AllocateNewPageMappingsCS — one thread per requested page-table entry not already mapped: PopPhysicalPageList(AVAILABLE); if the popped physical page still holds a valid older mapping, zero out that victim's PT entry and page flags first, then write the new PT entry (ALLOCATED|DYNAMIC_UNCACHED|STATIC_UNCACHED). Pool exhaustion = silent unmapped region (over-subscription: requests simply get no backing; an overflow stat flag VSM_STAT_OVERFLOW_FLAG_PAGE_POOL feeds a host-side warning) — sampling falls back to coarser mapped LODs via mip propagation. (5) AppendPhysicalPageLists merges lists so REQUESTED becomes next frame's LRU input.

## Hierarchical page flags (HMips) for O(1) overlap tests
PageFlags is a separate R32_UINT texture with the same per-VSM block layout, PLUS its own mip chain where each HMip texel is the bitwise OR of 2x2 finer page-flag texels (only the low 6 bits VSM_PAGE_FLAGS_BITS_PER_HMIP participate). GenerateHierarchicalPageFlags runs one thread per allocated physical page (not per PT entry!) and InterlockedOr's its flags up the pyramid, early-outing when a level already contains the bits. The same pass computes per-(VSM,mip) min/max page rects: AllocatedPageRectBounds (all mapped pages, for invalidation) and UncachedPageRectBounds (only pages needing rendering — used to clip cluster/instance rects during culling). Culling then tests an instance's page-space rect by picking HMip = MipLevelForRect (rect reduced to <=2x2), doing ONE 2x2 gather of hierarchical flags, and testing masks: ANY-semantics for ALLOCATED/UNCACHED bits, ALL-semantics for DETAIL_GEOMETRY/REQUEST bits (TestPageFlagMask).
[refs] VirtualShadowMapPageManagement.usf:162-264 (GenerateHierarchicalPageFlags, rect bounds); VirtualShadowMapPageAccessCommon.ush:13-39 (flag bits, 6 bits per HMip, TEST_ANY/TEST_ALL masks); VirtualShadowMapPageOverlap.ush:64-115 (GatherPageFlags + OverlapsAnyValidPage), 16-62 (page rect clip against UncachedPageRectBounds)

## Mip/clipmap fallback propagation (PropagateMappedMips)
After allocation, unmapped PT entries are filled with pointers to the best coarser mapped page so sampling never faults. Local lights: for each level-0 page column, walk mips coarse->fine; wherever a level is mapped (bThisLODValid) remember it; unmapped finer entries get ShadowEncodePageTable(coarserPhysAddr, LODOffset) (valid for sampling, NOT for rendering). Directional clipmaps use only mip 0 of each level-VSM; fallback instead searches successive coarser CLIPMAP levels (separate VSMs), adjusting page address by the per-level ClipmapCornerRelativeOffset (levels are camera-snapped so levels don't share a common origin), and writes a cross-VSM physical pointer with LODOffset=clipmap delta. This is why sampling only ever does one PT read.
[refs] VirtualShadowMapPageManagement.usf:268-399 (FMappedMipPropagator: directional clipmap search 299-333, local mip walk 339-383)

## Per-page draw command binning for non-Nanite (BuildPerPageDrawCommands)
Key insight: geometry is NOT binned per page — it is culled per mip-view against the page mask, then rasterized once per mip/clipmap view with the pixel shader scattering into physical pages. CullPerPageDrawCommandsCs: one thread per (instance, draw command) from the visible-instance work queue; for each primary shadow view then each mip level (each mip is a distinct 'mip view' with its own viewport = 16k>>mip): frustum cull, compute the instance's conservative screen rect in that mip's virtual space, clip it to UncachedPageRectBounds, convert to a page rect (pixels >> 7), and call OverlapsAnyValidPage (hierarchical flag gather, with uncached + detail-geometry mask from GetPageFlagMaskForRendering; small instances with est. footprint < CoarsePagePixelThreshold* are 'detail geometry' and skip coarse pages). Optional per-page HZB occlusion test (IsVisibleMaskedHZB). Survivors also mark overlapped pages dirty (invalidation flags) — rects <= 32 pages inline in-thread, larger rects deferred to a group-shared job queue processed by the whole group. Surviving (instance, mip-view) pairs append an FVSMVisibleInstanceCmd {PackedPageInfo(viewId,bStaticPage), InstanceId, IndirectArgIndex} and bump the indirect-draw instance count; a prefix-allocation pass (AllocateCommandInstanceOutputSpaceCs) then OutputCommandInstanceListsCs scatter instances into final per-draw ID lists. At raster time each mip view renders with viewport clipped to the uncached page rect; the depth-only PS translates virtual->physical per pixel (page table lookup) and InterlockedMax's into the pool, discarding pixels on unmapped/cached pages.

## Static/dynamic split caching + HZB
Two pool slices: static geometry renders into slice 1, dynamic into slice 0; when a page's static set is unchanged only dynamic re-renders and MergeStaticPhysicalPagesIndirectCS composites static into the dynamic slice (merge = per-texel max). Page flags track DYNAMIC_UNCACHED / STATIC_UNCACHED independently; physical metadata carries extended flags (INITIALIZED/DIRTY/INVALIDATE per slice, UNREFERENCED, FORCE_CACHED, DEFERRED_INVALIDATION with per-frame budget). SelectPagesToInitializeCS + InitializePhysicalPagesIndirectCS clear only the pages that need it (indirect dispatch over selected page list; clear = 0 or copy static->dynamic). Per-page HZB: BuildHZBPerPageCS builds a 7-level (Log2PageSize) min-depth pyramid per 128x128 physical page for occlusion culling of casters next frame, optionally a separate HZB array slice for the static-only layer.
[refs] VirtualShadowMapPageAccessCommon.ush:41-70 (extended flags); VirtualShadowMapPhysicalPageManagement.usf:851-1090 (select/init/merge), 1643-1916 (dirty flags + BuildHZBPerPage); VirtualShadowMapArray.h:82-86 (NumHZBLevels=Log2PageSize), 163-165 (StaticCachedArrayIndex/StaticHZBArrayIndex)

## Single-page (distant light) shadow maps
The first 8192 VirtualShadowMapId values (VSM_MAX_SINGLE_PAGE_SHADOW_MAPS = 1024*8) are reserved for 'distant' local lights that get exactly ONE 128x128 page (logically the last mip). Their PT entries pack densely into the first 128x128 block of the page-table texture, so 8k distant lights cost 8k PT texels + <=8k physical pages. They're marked via MarkCoarsePages (always mark last mip), skip dynamic invalidation (round-robin refreshed instead), and sampling clamps to mip 7. ID-space ordering rule: single-page locals, then directional (always full), then full locals, then unreferenced (VirtualShadowMapArray.h:589-593).
[refs] Definitions.h:67; VirtualShadowMapPageAccessCommon.ush:131-136, 189-194, 364; VirtualShadowMapArray.h:58-61, 318-335, 589-597; VirtualShadowMapPageMarking.usf:861-872

## Receiver masks (sub-page culling refinement)
Optional per-page 8x8 bitmask of which 16x16-texel sub-tiles actually contain a marked receiver, stored as 2x2 uints of 4x4 bits (atomics require 32-bit words) in a texture 2x the page-table size, with its own OR'd mip pyramid. Marking sets the bit for the receiver's sub-tile; caster culling (OverlapsAnyValidPage with bUseReceiverMask) intersects the caster's sub-page rect against the gathered 8x8 mask (IntersectMask8x8) to reject casters that overlap a needed page but no needed texels. Cost: pages with receiver masks force VSM_FLAG_DYNAMIC_UNCACHED every frame (page may be incomplete for caching).
[refs] Definitions.h:30-34 (8x8); VirtualShadowMapArray.h:516-517; VirtualShadowMapPageMarking.ush:62-80; VirtualShadowMapPageOverlap.ush:117-205; VirtualShadowMapPhysicalPageManagement.usf:373-377
