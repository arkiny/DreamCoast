TOPIC: UE5 Virtual Shadow Maps — page caching + dynamic-object invalidation (VirtualShadowMapCacheManager, cache invalidation shaders, physical page management)

FRAME FLOW:
Per frame (relative to scene update and shadow rendering): (1) PreLightsUpdate: drop cache entries of removed lights. (2) PreSceneUpdate (old transforms still on GPU): collect Removed + UpdatedTransform + always-invalidating primitives -> ProcessInvalidations -> InvalidateInstancePagesLoadBalancerCS marks INVALIDATE_STATIC/DYNAMIC bits into LAST frame's PageRequestFlags texture, using last frame's page table/flags/HZB. (3) GPUScene update uploads new transforms. (4) PostGPUSceneUpdate: collect Added + UpdatedTransform (new footprints) -> same GPU invalidation pass; also reset per-view instance-state words for added primitives; UpdateCachePrimitiveAsDynamic runs inside each ProcessInvalidations (mark invalidated prims dynamic, demote >100-frame-quiet prims back to static with FORCE_STATIC invalidations). (5) Scene renderer PreRender (post-visibility): VSMUpdateViewInstanceStateCS diffs GPU deforming bits vs persistent state, queues transitions-to-dynamic -> ProcessInvalidationQueueGPUCS invalidates dynamic pages only. (6) VSM update: per-light cache entries Update/UpdateClipmapLevel decide KEEP_PAGE + clipmap PageAddressOffset; page marking writes this frame's PageRequestFlags; UpdatePhysicalPageAddresses remaps physical metadata to new VSM ids/scrolled addresses and pulls INVALIDATE_* bits from prev PageRequestFlags onto physical pages; UpdatePhysicalPages converts them (dynamic-only -> DYNAMIC_UNCACHED, static -> both UNCACHED) into hierarchical page flags + page table entries, ages out stale pages via LRU lists; AllocateNewPageMappings pops free pages for new requests (born fully uncached). (7) SelectPagesToInitialize + InitializePhysicalPagesIndirect: dynamic layer of each to-render page is seeded by copying the cached static slice (or cleared); static layer cleared only if STATIC_UNCACHED. (8) Shadow depth rendering: static-classified casters draw into static slice only where STATIC_UNCACHED; dynamic casters draw into slice 0 where DYNAMIC_UNCACHED; rendering feeds 6-slice DirtyPageFlags (incl. WPO-allowed -> FORCE_CACHED, receiver-mask invalidations). (9) Post-process: UpdateAndClearDirtyFlags folds dirty bits into physical metadata; pages with STATIC_DIRTY get MergeStaticPhysicalPagesIndirectCS (slice0 = max(slice0, static)); HZB rebuilt for dirty pages. (10) Projection samples slice 0 only. (11) ExtractFrameData saves PageTable/PageFlags/PageRequestFlags/ProjectionData/etc. as PrevBuffers for next frame's invalidations.

CONSTANTS:
Page geometry: VSM_PAGE_SIZE=128 (VSM_LOG2_PAGE_SIZE=7), page table 128x128 pages (VSM_LOG2_LEVEL0_DIM_PAGES_XY=7), VSM_MAX_MIP_LEVELS=8, virtual resolution 16384^2 (Definitions.h:13-20). Physical pool: R32_UINT Texture2DArray, TexCreate_UAV|AtomicCompatible, optionally reserved-resource committed (CacheManager.cpp:1114-1125); static layer = extra array slice (StaticCachedArrayIndex). DirtyPageFlags slices = 6 (Definitions.h:24). Caching cvars (defaults): r.Shadow.Virtual.Cache=1; Cache.InvalidateUseHZB=1 (occlusion-cull invalidations); Cache.DeformableMeshesInvalidate=1; Cache.MaxPageAgeSinceLastRequest=1000 frames; Cache.MaxLightAgeSinceLastRequest=10 frames; Cache.FramesStaticThreshold=100 frames (dynamic->static demotion age); Cache.CPUCullInvalidationsOutsideLightRadius=1; Clipmap.WPODisableDistance.InvalidateOnScaleChange=0 (CacheManager.cpp:97-203). Clipmap: snap size = level radius, RadiiPerLevel=4, page offset unit = Level0DimPagesXY>>2 = 32 pages (Clipmap.cpp:336, :364-402); Z guardband invalidation factor 0.9 (CacheManager.cpp:279); ViewRadiusZ = levelRadius * r.Shadow.Virtual.Clipmap.ZRangeScale (Clipmap.cpp:352, :397). Invalidation HZB depth epsilon = 1e-8 (CacheInvalidation.ush:115). Payload packing: 8 flag bits + 24-bit VSM id (Definitions.h:69-72); GPU queue item: InstanceId(24b)<<8 | viewId(7b)<<1 | stateChange(1b) (CacheGPUInvalidation.usf:19-24). Page flags (hierarchical, PageAccessCommon.ush:15-39): ALLOCATED=1<<0, DYNAMIC_UNCACHED=1<<1, STATIC_UNCACHED=1<<2, DETAIL_GEOMETRY=1<<3, PRIMARY/SECONDARY_REQUEST=1<<4/5. Extended (physical metadata only, :45-70): DYNAMIC/STATIC_INITIALIZED=1<<6/7, DYNAMIC/STATIC_DIRTY=1<<8/9, INVALIDATE_DYNAMIC/STATIC=1<<10/11, VIEW_UNCACHED=1<<12, UNREFERENCED=1<<13, FORCE_CACHED=1<<14 (WPO), DEFERRED_INVALIDATION=1<<15. NextData flags: VSM_NEXT_FLAG_KEEP_PAGE=1<<0 (Definitions.h:136). Merge op = per-texel max(dynamic, static) (reverse-Z depth as uint; PhysicalPageManagement.usf:808-810). Init/merge tile kernels: 16x16 threads, 2x2 texels/thread, 32x32-texel tiles, 16 tiles/page (:813-832).

DREAMCOAST NOTES:
Adaptation guidance for DreamCoast (single sun + point lights, no Nanite, rigid node-animated characters, bindless RHI, render graph): (1) The minimal viable core is: persistent physical page pool (one R32_UINT array texture + metadata buffer, atomics-friendly on all three backends), per-frame rebuilt page table, prev-frame PageRequestFlags as the invalidation mailbox, and the UpdatePageAddresses -> UpdatePages -> Initialize -> render -> merge pipeline. UE's split of 'hierarchical page flags' (per-virtual-page, mip chain for cheap rect tests) vs 'extended flags' (per-physical-page metadata) is worth copying exactly — the invalidation pass only ever ORs bits into a request-flags texture, which makes it trivially safe with the render graph. (2) The static/dynamic dual-layer scheme maps perfectly to rigid node-animated dungeon characters: classify them dynamic (equivalent of CachePrimitiveAsDynamic bit per mesh instance), re-render only slice-0 dynamic layers of pages they overlap each frame (seed by copying static slice), keep all level geometry static-cached. Because DreamCoast movers are rigid transforms (no skinning/WPO in shadow path yet), the whole GPU deforming-bit machinery (VSMUpdateViewInstanceStateCS, per-view 2-bit state, transition queue) can be skipped — CPU transform-change tracking (S1 cache already hashes caster transforms per epoch, see windows-parity memory) is the exact analogue of UE's PreSceneUpdate/PostGPUSceneUpdate double invalidation; just remember UE invalidates BOTH old and new footprints (pre + post GPUScene update). One CPU-filled instance-range list + one compute dispatch (AABB -> frustum cull -> page rect -> InterlockedOr) is the whole GPU side. (3) For the sun, the clipmap page-scroll trick (snap ortho to whole-page multiples, store per-level FInt64Point page-space location, pass int2 offset to the remap dispatch, drop out-of-range pages) plus the 0.9 Z-guardband rule is the difference between 'cache useless while camera moves' and 'cache survives'; DreamCoast's dungeon CSM=2 could adopt this per cascade. (4) The 100-frame quiet-demotion (dynamic->static with a one-time forced static invalidation) is a cheap, robust hysteresis — and note it does NOT violate the no-freeze directive in memory: nothing is latched; every state change generates an explicit invalidation, and staleness is bounded by MaxPageAgeSinceLastRequest. (5) Watch cross-backend gotchas: page pool uses uint depth atomics (InterlockedMax at raster time — needs VK/DX/Metal atomic image support parity; UE uses R32_UINT + AtomicCompatible); the merge is max() because reverse-Z — DreamCoast shadow depth convention must be checked; HZB-culled invalidations are an optimization, safe to omit initially (set r.Shadow.Virtual.Cache.InvalidateUseHZB=0 equivalent). (6) Start with UE's conservative correctness rules: new pages born fully uncached; any static invalidation implies dynamic too; unreferenced pages keep their invalidation flags until re-referenced (PhysicalPageManagement.usf:299-314) — this last one is an easy-to-miss correctness detail that prevents stale shadows for offscreen lights. Quality knobs to expose in quality.rs tiers: page size (UE fixed 128), pool size, FramesStaticThreshold, max page age, HZB-invalidation on/off.

MECHANISMS:

## Persistent cross-frame state (what survives a frame)
The physical page pool is owned by the cache manager, NOT the per-frame VSM array: PhysicalPagePool is a R32_UINT Texture2DArray (depth as uint atomics) plus PhysicalPageMetaData (one FPhysicalPageMetaData per physical page: Flags, LastRequestedSceneFrameNumber, VirtualShadowMapId, MipLevel, PageAddress). Per-frame virtual-side buffers are ping-ponged via ExtractFrameData into PrevBuffers (FVirtualShadowMapArrayFrameData: PageTable, PageFlags, PageRequestFlags, PageReceiverMasks, ProjectionData, PhysicalPageLists, Allocated/UncachedPageRectBounds). CPU side persists: CacheEntries map keyed by {ViewUniqueID, LightSceneId, ShadowTypeId}; per-light FVirtualShadowMapPerLightCacheEntry (RenderedFrameNumber, cache keys, per-shadow-map FVirtualShadowMapCacheEntry with NextData = prev->next VSM id remap + clipmap page offset); CachePrimitiveAsDynamic bit array + LastPrimitiveInvalidatedFrame array indexed by persistent primitive index; per-persistent-view InstanceState buffer (2 bits/instance: CacheAsDynamic, IsTracked). A cached page is reused when the page-update pass finds a request for the same (VSM id, mip, page address) and no invalidate flags: it rewrites the page-table entry to point at the existing physical page and leaves only VSM_FLAG_ALLOCATED set, so both rendering layers skip it. Unrequested pages survive up to MaxPageAgeSinceLastRequest frames in an LRU list; unreferenced (offscreen) lights get their VSM ids re-allocated each frame (UpdateUnreferencedCacheEntries) so their pages persist.

## Static/dynamic caster separation — two depth layers per physical page
Each physical page exists twice in the pool texture array: slice 0 is the 'final/dynamic' layer, slice VirtualShadowMap.StaticCachedArrayIndex is the static-cached layer (GetVirtualShadowMapStaticArrayIndex, PageAccessCommon.ush:395). Draw packets carry FPageInfo.bStaticPage (1 bit in packed page info, :373-393) selecting the destination slice. An instance is routed to the static layer iff ShouldCacheInstanceAsStatic(instance) (PageCacheCommon.ush:94-116): view not uncached, WPO not allowed, primitive bit in CachePrimitiveAsDynamic clear, and per-view instance CacheAsDynamic bit clear. Per-page re-render is gated by hierarchical page flags: static-cached instances only render into pages with VSM_FLAG_STATIC_UNCACHED, dynamic instances into pages with VSM_FLAG_DYNAMIC_UNCACHED (GetPageFlagMaskForRendering, PageOverlap.ush:334-346). Merging is NOT at sample time: (1) when a page's dynamic layer must re-render but static is still cached, InitializePhysicalPagesIndirectCS seeds slice 0 by copying the static slice (PhysicalPageManagement.usf:997-1008), else clears to 0; (2) after rendering, if the static layer was written this frame (VSM_EXTENDED_FLAG_STATIC_DIRTY), SelectPagesToPostProcessCS emits the page (:1061-1069) and MergeStaticPhysicalPagesIndirectCS folds it in with max(dynamic, static) per texel into slice 0 (:805-811, :1076-1086). Projection/sampling always reads slice 0 only. Flag bits: VSM_FLAG_ALLOCATED/DYNAMIC_UNCACHED/STATIC_UNCACHED/DETAIL_GEOMETRY (PageAccessCommon.ush:15-39) live in the hierarchical page-flag mips; VSM_EXTENDED_FLAG_{DYNAMIC,STATIC}_{INITIALIZED,DIRTY}, INVALIDATE_{DYNAMIC,STATIC}, VIEW_UNCACHED, UNREFERENCED, FORCE_CACHED, DEFERRED_INVALIDATION (:45-70) live only on physical page metadata.

## CPU invalidation triggers (transform change / add / remove / deformable)
FVirtualShadowMapInvalidationSceneUpdater is a scene-extension updater. PreSceneUpdate (before GPUScene update, while old transforms still live on GPU): feeds UpdatedTransform for every primitive in the change set with culling-dirty flags, Removed for deletes, plus ShadowScene's AlwaysInvalidatingPrimitives list (cpp:2044-2072). PostGPUSceneUpdate (after new transforms uploaded): feeds Added and UpdatedTransform again (:2173-2192) — so a moved object invalidates BOTH its old and new footprint. The FInvalidatingPrimitiveCollector filters: skips lights that are fully-cached-distant, uncached, or already invalidated (:474, :615); skips primitives that don't cast dynamic shadows (:557-561); 'Updated' is suppressed if proxy behavior == EShadowCacheInvalidationBehavior::Static (:570-577); 'Added' only marks dynamic if IsMeshShapeOftenMoving (:579-588); CPU-culls per light via bounds vs light radius (AffectsBounds, h:165-169, cvar GVSMLightRadiusInvalidationCulling). Each surviving (instance-range, light) pair is appended to an instance GPU load balancer with payload = VirtualShadowMapId << 8 | flags (EncodeInstanceInvalidationPayload :442-449), one item per clipmap level/cube face for load balancing (:636-642). Ranges come straight from GPUScene: PrimitiveSceneInfo->GetInstanceSceneDataOffset()/GetNumInstanceSceneDataEntries(). Separately, OnPrimitiveRendered (:1281-1312) queues per-light invalidations every frame for proxies with HasDeformableMesh() (skinned/vertex-animated, GVSMCacheDeformableMeshesInvalidate) and for 'revealed' primitives (transitioned from CPU-culled to visible; tracked by the per-light RenderedPrimitives bit array); reveal does not mark the primitive dynamic.

## GPU invalidation dispatch — instance bounds -> page overlap -> flag marking
ProcessInvalidations builds a uniform buffer from PREVIOUS frame VSM state (page table, page flags, allocated page rect bounds, projection data — GetUniformParametersForInvalidation :1902-1935) and dispatches InvalidateInstancePagesLoadBalancerCS over the collected instance ranges (:1960-1990). Core shader InvalidateInstancePages (CacheInvalidation.ush:43-163): for each (instance, VSM): distance-cull vs local light radius (:53-61); frustum-cull the instance's local-space AABB against the shadow view (BoxCullFrustum with UV->clip matrix, ortho for directional); loop mips (clipmaps = 1 level, local lights = all 8 mips), compute the covered page rect clipped to the ALLOCATED page rect bounds (VirtualShadowMapGetAllocatedPageRect :119); early-out via hierarchical page-flag mip test (OverlapsAnyValidPage :125); optional HZB occlusion test against the SHADOW HZB so fully occluded movers don't invalidate (USE_HZB_OCCLUSION, cvar r.Shadow.Virtual.Cache.InvalidateUseHZB; depth epsilon +1e-8 :115); then for each overlapped allocated page InterlockedOr's VSM_EXTENDED_FLAG_INVALIDATE_STATIC or _DYNAMIC into the PREV PageRequestFlags texture (:155) — chosen by whether the instance was cached-as-static (:84-90); a FORCE_STATIC payload overrides to invalidate static (used when demoting dynamic->static). Marking request flags rather than the page table is deliberate: pages not requested this frame aren't in the page table but must still be invalidated (:152-154). Consumption happens next frame: UpdatePhysicalPageAddresses copies INVALIDATE_* bits from PrevPageRequestFlags onto physical page metadata (PhysicalPageManagement.usf:203-213); UpdatePhysicalPages then converts INVALIDATE_DYNAMIC-only into VSM_FLAG_DYNAMIC_UNCACHED (static stays cached) and INVALIDATE_STATIC into VSM_FLAG_ANY_UNCACHED (both layers re-render) (:321-342).

## Dynamic<->static classification lifecycle (age-based demotion/promotion)
Any invalidation of a primitive sets CachePrimitiveAsDynamic[persistentIdx]=true and stamps LastPrimitiveInvalidatedFrame with the scene frame (UpdateCachePrimitiveAsDynamic :1774-1782). Removal clears both (:1786-1795). Every frame, each currently-dynamic primitive whose invalidation age exceeds r.Shadow.Virtual.Cache.FramesStaticThreshold (default 100) is flipped back to static: a FORCE_STATIC-flagged invalidation is queued for every shadow map of every cached light (so its cached static footprint gets re-rendered including the object), and the bit is cleared (:1797-1849). The bit array is uploaded to the GPU each invalidation pass (UploadCachePrimitiveAsDynamic :1229-1244) and read by ShouldCacheInstanceAsStatic at render/cull time — so the SAME classification drives both which layer an instance renders to and which INVALIDATE_* flag its movement sets. Net protocol for a moving rigid object: frame N move -> marked dynamic + old/new footprints' STATIC layers invalidated once; frames N+1..N+100 it renders into the dynamic layer every frame (pages it touches are marked via a separate per-frame mechanism: receiver masks or dynamic-uncached flags) while static underneath stays cached; frame N+101 (no moves) one final static invalidation folds it back into the static layer.

## GPU-driven per-instance deforming-state invalidation (newer path, per-view)
For instances whose 'deforming' state is computed GPU-side (GPUScene per-view deforming bits, ViewData.ush:77-94), VSMUpdateViewInstanceStateCS runs one thread per 32-instance word (CacheGPUInvalidation.usf:66-141): loads IsDeformingMask from GPUScene, compares with the persistent per-view CacheAsDynamic word, uses a second 'tracked' word so newly added instances don't spuriously invalidate; writes new state to persistent buffer + a transient 2-words-per-view buffer (current state + transition mask) exposed via scene UB (Scene.VSMCache.CacheInstanceAsDynamic, read by GetCacheInstanceAsDynamic / GetCacheTransitioned in PageCacheCommon.ush:64-92). Only transitions TO dynamic append to a GPU invalidation queue (packed InstanceId<<8 | viewId<<1 | stateChange, :19-24, :123-140); transitions to static deliberately do NOT invalidate ('double shadow' accepted, :123-126) — instead GetPageFlagMaskForRendering returns ALLOCATED|DYNAMIC_UNCACHED for just-transitioned static instances so they render on top (PageOverlap.ush:337-344). ProcessInvalidationQueueGPUCS then consumes the queue indirectly, brute-forces all full VSMs, matches the item's view id against each VSM's SceneRendererPrimaryViewId (persistent-view remapped), and calls InvalidateInstancePages with OverrideInvalidationFlags=VSM_EXTENDED_FLAG_INVALIDATE_DYNAMIC only (:145-193). VSMResetInstanceStateCS clears state words for newly added primitives' instance ranges with word-boundary masking (:197-236). CPU orchestration: PostGPUSceneUpdate sizes buffers (2 bits x instances x views), PreRender runs state-update per view then the queue processing (CacheManager.cpp:2127-2354).

## Clipmap scrolling — page-space offsets keep directional pages valid under camera motion
Each clipmap level is an ortho view snapped in light-view XY to SnapSize = level radius; the level's integer snap coordinates produce CornerOffset, and PageOffset = CornerOffset * (Level0DimPagesXY>>2) — i.e. one snap unit = 32 pages = a quarter of the 128-page table (Clipmap.cpp:356-402; RadiiPerLevel=4 :336). UpdateClipmapLevel (CacheManager.cpp:259-314) compares new vs cached FInt64Point PageSpaceLocation; if the cache is valid it sets NextData.Flags=VSM_NEXT_FLAG_KEEP_PAGE and NextData.PageAddressOffset = current-previous page offset. GPU pass UpdatePhysicalPageAddresses applies this: newPageAddress = prevPageAddress + PageAddressOffset; pages that scroll outside the valid [0,128) page-table range fail IsVirtualShadowMapPageAddressValid and are dropped (Flags=0) (PhysicalPageManagement.usf:182-218). So the page TABLE is rebuilt every frame but physical pages logically slide; texel-level validity holds because the ortho projection translates in whole-page multiples. Z survives movement via a guardband: ViewRadiusZ = levelRadius * r.Shadow.Virtual.Clipmap.ZRangeScale, and the cached level is invalidated only when |newCenterZ - cachedCenterZ| + levelRadius > 0.9 * cached ViewRadiusZ, or ViewRadiusZ itself changed (:272-284); while cached, the ViewToClip Z offset is rebuilt against the CACHED center (ViewCenterDeltaZ, Clipmap.cpp:435-459) so depths stay comparable. Light DIRECTION change invalidates the whole light: FClipmapCacheKey{LightDirection, FirstLevel} mismatch sets RenderedFrameNumber=-1 (CacheManager.h:135-144, cpp:361-397). Any per-light invalidation also flips the light to bIsUncached for the next frame (continuously rotating suns automatically take the cheaper uncached path; one static frame flips back, with a forced invalidation on the cached<->uncached transition because static pages may be uninitialized) (:376-389).

## WPO / material-driven 'dynamic' policy + render-time dirty feedback
A caster is material-dynamic if it evaluates world-position-offset: ShouldMaterialInvalidateShadowCache = bEnableWPO OR primitive has always-evaluate-WPO materials, unless the primitive opts out via DISABLE_MATERIAL_INVALIDATIONS flag (PageCacheCommon.ush:11-21). VirtualShadowMapIsWPOAllowed additionally honors a per-clipmap-level WPO disable distance: WPO is only 'allowed' if the level's ClipmapLevelWPODistanceDisabledThresholdSquared <= instance WPO disable distance (:26-44) — distant clipmap levels treat WPO meshes as static. WPO-allowed instances are forced onto the dynamic layer (ShouldCacheInstanceAsStatic returns false when bAllowWPO). Rather than invalidating every frame, rendering marks overlapped pages through 6 DirtyPageFlags slices (dynamic-dirty, static-dirty, invalidates-dynamic, invalidates-static, WPO-allowed, deferred-invalidation; VSM_DIRTY_PAGE_FLAGS_NUM_SLICES=6, Definitions.h:24). UpdateAndClearDirtyFlags folds these into physical-page flags post-render (PhysicalPageManagement.usf:1580-1625): WPO-allowed -> VSM_EXTENDED_FLAG_FORCE_CACHED, which next frame causes the page to set DYNAMIC_UNCACHED in hierarchical flags (so WPO casters are re-considered/re-rendered into the dynamic layer) WITHOUT treating the page as truly invalidated (:434-448, WPO_CONSIDERED_PAGES stat). CPU-side knobs: proxy HasDeformableMesh() (skinned) => per-frame invalidation via OnPrimitiveRendered; EShadowCacheInvalidationBehavior::{Auto, Always (ShadowScene AlwaysInvalidatingPrimitives, fed as UpdatedTransform every frame, CacheManager.cpp:2051-2054), Static (suppress all update invalidations), Rigid}. WPO threshold changes (FOV/resolution driven) can optionally invalidate whole clipmap levels (CVarClipmapWPODisableDistanceInvalidate, default 0; CacheManager.cpp:286-295).

## Whole-cache and per-light drop paths
FVirtualShadowMapArrayCacheManager::Invalidate simply resets PrevBuffers to empty (cpp:1189-1193) — with no prev page table/flags, IsCacheDataAvailable()==false and everything re-renders; physical pool survives but all mappings die. Triggered by: physical pool resize/recreate or create-flag change (:1090-1143), HZB pool resize (:1155-1178), pool free. Per-light: light removed from scene -> ProcessRemovedLights drops the cache entries so reused light IDs can't alias stale pages (:1890-1900); clipmap level-count change recreates the entry (:1257-1269); lights unreferenced for > r.Shadow.Virtual.Cache.MaxLightAgeSinceLastRequest (10) frames are aged out in UpdateUnreferencedCacheEntries. Local-light cache key = {WorldToLight matrix, PreShadowTranslation, bIsDistantLight} — any light move/rotate invalidates that light wholesale (h:146-154). Distant local lights are special: IsFullyCached => they skip per-primitive invalidation entirely (collector skips them) and are refreshed round-robin instead.
