FRAME FLOW:

Fallbacks: RayCount=0 → single sample + optimal slope bias; unmapped everywhere at origin/beyond last level → fully lit. DREAMCOAST NOTES:
Directly relevant to our CSM wall-base texel-straddle leak: UE attacks exactly this with a *receiver-plane texel-center offset bias* — ComputeVirtualShadowMapOptimalSlopeBias (ProjectionCommon.ush:329-360) computes depth-slope-per-UV from the geometric normal (via a WorldToShadowUV *normal* matrix) and dots it with the offset from the sample point to the fetched texel's center, so the compare depth is corrected for where inside the straddled texel the receiver actually is. This is cheap (a matrix mul + dot per tap), has no magic world-space constants, and ports 1:1 to our CSM PCF taps in pbr.slang — we already have world normal in the G-buffer. Complements: (1) distance-scaled normal-offset bias max(0.02, k*dist/cotHalfFOV) instead of any constant depth bias — with our 25cm-bias floating-shadow history (dungeon CSM app default), moving to receiver-derived bias is the root-cause fix; (2) screen-space pre-ray (0.015*depth, 4 taps against our existing depth buffer) as a 'smart bias' start offset — works with our deferred G-buffer world-pos; (3) if we later want penumbra: SMRT is PCF-free — 7 rays x 8 samples with quadratic receiver-dense spacing, DepthHistory slope extrapolation (clamp 5.0) is the leak guard at silhouettes, and adaptive wave votes cut cost in umbra/lit (we have wave ops in Slang on VK/DX12). Clipmap side if we outgrow CSM: radial log2 level select is simpler than our split-scheme math, per-level snap = level radius (32 pages) enables cache scrolling, ZRangeScale~1000 pinning is what makes caching survive camera Z motion; page table entry encoding (20b addr + 6b LOD-offset redirect) gives single-fetch fallback — bindless-friendly, no feedback loop needed since marking is receiver-driven from the depth buffer. Depth: reversed-Z float32-in-uint pool matches our existing conventions. Constants worth copying verbatim: slope clamp 0.05 UV, 2x bias factor, tolerance 1.05x step, dither 2.0 texels, blue-noise mask dither 1/15.

MECHANISMS:

## Clipmap level scheme (log2-radial, per-level ortho VSMs)
One directional light = a stack of independent 16k-virtual ortho shadow maps (one FVirtualShadowMap per clipmap level). Absolute level L covers a radius of 2^(L+1) around the clipmap origin (GetLevelRadius: pow(2, Level+1) — 'rounds down, so radius covers out to 2^(L+1)'). Levels run FirstLevel..LastLevel (defaults 6..22 via r.Shadow.Virtual.Clipmap.FirstLevel/LastLevel; note the header defaults 8/18 are overridden by cvars), so up to 17 levels; each extra level doubles max range. Each level's ortho projection spans 4x the level radius across (RadiiPerLevel=4: FReversedZOrthoMatrix(HalfLevelDim=2*R, ...) => ±2R). Level for a receiver is chosen RADIALLY, not by screen footprint: AbsoluteLevel = log2(distance from receiver to clipmap origin) (CalcAbsoluteClipmapLevel = 0.5*log2(dist²)), then a resolution LOD bias is added and floor() gives the level; ClipmapIndex = AbsoluteLevel - FirstLevel. Screen resolution enters through ResolutionLodBias computed on CPU: LodScale = (0.5/ProjectionScale.X) * (VirtualMaxRes 16384 / CameraViewportWidth); ResolutionLodBias = clamp0(baseBias + log2(LodScale)) — i.e. instead of resizing the virtual maps, sampling is biased to coarser levels when the viewport is small/FOV wide. Roll invariance relies on square pixels (only X scale used).

## Per-level origin snapping + cache scrolling offsets
Clipmap WorldOrigin = camera position (ortho cameras optionally project to ViewTarget/raycast hit). Each level snaps its center independently in LIGHT-VIEW XY space to a grid of SnapSize = level radius R (RoundToDouble(ViewCenter/R)*R), so a level's origin moves in steps of R = 1/4 of its extent = 32 pages (PageOffset = CornerOffset * (Level0DimPagesXY>>2) = CornerOffset*32). CornerOffset (in radii) is stored per level; a RelativeCornerOffset vs. the LastLevel-snapped origin is kept in small ints for LWC precision and uploaded to the GPU (ClipmapCornerRelativeOffset) — the shader reconstructs UV/page offsets between levels from it. The cache manager receives PageOffset and scrolls cached physical pages instead of invalidating on camera motion. Depth range per level: ViewRadiusZ = R * ZRangeScale (r.Shadow.Virtual.Clipmap.ZRangeScale default 1000) around the view-center Z; when cached, the cached level PINS its ViewCenterZ/ViewRadiusZ and the new matrix compensates with ViewCenterDeltaZ in ZOffset so cached page depths stay valid (comment: huge Z range chosen so camera Z motion doesn't invalidate; too large => depth precision flicker).

## Page-table walk per sample + non-resident fallback (single fetch)
Page table: 128x128 pages of 128x128 texels (=16384² virtual). SampleVirtualShadowMapClipmap does ONE page-table fetch at the requested clipmap level; the 32-bit entry encodes PhysicalAddress (10+10 bits), LODOffset (6 bits, [0..64)), and flags bAnyLODValid/bThisLODValidForRendering. For clipmaps the mip-LODOffset field is repurposed as 'mapped LevelOffset to a coarser CLIPMAP level' (hierarchical pointers written by page management, cf. PropagateMappedMips), so a miss does NOT loop: if LODOffset>0 the shader computes the coarser level's page via pure integer math (CalcClipmapOffsetLevelPage, using ClipmapCornerRelativeOffset scaled by Level0DimPages/4) and rescales UV+depth with CalcClipmapRelativeTransform: Scale=1/2^offset, Bias.xy = 0.25*(OffsetB - Scale*OffsetA), Bias.z from the two levels' ShadowViewToClip[3][2]; sampled depth is converted back into the reference level basis: Depth=(raw-Bias.z)/Scale. If bAnyLODValid==false the sample is invalid — SMRT skips it (counts as no data, not lit/shadowed); if the receiver is beyond the last level entirely, result = fully lit (ShadowFactor=1). Physical pool texel = PhysicalAddress*128 + (VirtualTexel & 127); depth read as asfloat(uint pool load). Additionally GetMappedClipmap probes the page table once at the ray origin and starts SMRT at the best actually-mapped level to avoid per-sample fallbacks.

## SMRT — shadow-map ray marching replaces PCF
Per receiver pixel: N rays (default 7, r.Shadow.Virtual.SMRT.RayCountDirectional) toward random points on the sun disk (UniformSampleDiskConcentric * Light.SourceRadius, blue-noise driven), each ray-marched in shadow UVZ space with M samples (default 8, SamplesPerRayDirectional). Ray world length = SMRTRayLengthScale (default 1.5, RayLengthScaleDirectional) * distance-from-view-origin — penumbra size vs contact-detachment tradeoff. Sample times: SampleTime = Pow2(TimeScale*i + TimeBias) with TimeScale=-1/M — QUADRATIC spacing marching from the far end (t≈1, toward light) down to t=0 at the receiver, i.e. densest sampling near the receiver => contact hardening. Hit test per valid sample: occluded if SampleDepth > ReferenceDepth (reversed-Z: larger = closer to light) within a RELATIVE tolerance CompareTolerance = |ΔReferenceDepth per step| * 1.05; hit only when abs(DepthDiff + 0.5*Tol) < 0.5*Tol (one-sided interval == occluder within one step of the ray). LIGHT-LEAK handling at depth discontinuities: the marcher keeps DepthHistory + DepthSlope; when a sample is 'behind' (occluder much nearer to light than the ray — i.e. the ray walked under a silhouette edge), it does NOT compare against the raw sample but against an extrapolation of the last-seen surface: DepthForComparison = DepthSlope*Δt + DepthHistory, with DepthSlope clamped to ±ExtrapolateMaxSlope (directional default 5.0, scaled by |_33| so it's ZRangeScale-invariant). This extends occluders across the discontinuity instead of leaking. ShadowFactor = missCount/rayCount; OccluderDistance = avg over hit rays via ComputeOccluderDistanceOrtho((d - _43)/_33 difference). Adaptive early-out (SMRT.AdaptiveRayCount=1): wave-vote after ray 0 (all lanes miss => lit) and after 2 rays (no lane missed => umbra). Fallback when RayCount==0: single-sample SampleVirtualShadowMapDirectional with optimal slope bias.

## Bias stack (no constant depth bias; receiver-derived only)
Four cooperating biases, all receiver-derived (this is how VSM avoids peter-panning with tiny texels): (1) NORMAL BIAS: receiver position offset along the GEOMETRIC normal before projection, length = max(0.02, 0.5 * DistanceToCamera / cotHalfFOV) (r.Shadow.Virtual.NormalBias=0.5 — i.e. ~0.5 units per 100 units distance at 90° FOV; scales with screen texel footprint, not shadow texel). Skipped for subsurface/hair. (2) SCREEN-SPACE RAY ('smart bias'): before the SMRT ray, march 4 samples (SCREEN_RAY_SAMPLES) along the light direction in screen space against the scene depth buffer, length = r.Shadow.Virtual.ScreenRayLength(0.015) * SceneDepth; the distance reached becomes RayStartOffset — the VSM lookup starts off the surface, skipping the ambiguous first texels at the receiver (if the screen ray goes behind geometry it backs up 1.5 steps). RayStartOffset is converted to a depth bias via ShadowViewToClipMatrix._33 and any optimal bias already covered is subtracted. (3) OPTIMAL (receiver-plane) SLOPE BIAS: transform the receiver plane normal by TranslatedWorldToShadowUVNormalMatrix; DepthSlopeUV = -NormalPlaneUV.xy/NormalPlaneUV.z clamped to ±0.05 (SMRT path) — depth change per shadow UV; bias = 2 * max(0, dot(DepthSlopeUV, TexelCenterOffsetUV)) where TexelCenterOffsetUV is the offset from the sample point to the CENTER of the texel actually fetched ('2x due to precision'). This is exactly a texel-straddle correction: it accounts for the receiver's own depth variation across the texel. In the single-sample path it's clamped to 100*|_33| and multiplied by 2^(sampledLevel - requestedLevel) when a coarser fallback level was used. (4) TEXEL DITHER: random UV offset within ~a texel (SMRT.TexelDitherScaleDirectional=2.0 * per-light TexelDitherScale), its own slope-bias contribution computed from the same DepthSlopeUV so dithered taps don't self-shadow; DitherScale formula keeps it proportional to distance / exp2(level - lodBias).

## Matrices & depth convention (per level vs per light)
PER LIGHT (constant across levels): WorldToLightViewRotationMatrix = FInverseRotationMatrix(lightDir) * FaceMatrix (pure rotation; FaceMatrix remaps so view +Z runs along the light direction), LightDirection. PER CLIPMAP LEVEL: PreViewTranslation = -SnappedWorldCenter (LWC double, uploaded split high/low), ViewToClip = FReversedZOrthoMatrix(2R, 2R, ZScale=0.5/ViewRadiusZ, ZOffset=ViewRadiusZ+ViewCenterDeltaZ), plus derived TranslatedWorldToShadowUVMatrix (rotation*ortho*NDC->UV), its inverse, and TranslatedWorldToShadowUVNormalMatrix for plane/normal transforms. GPU-side per-level data also carries: packed ClipmapLevel+index+countRemaining (PackClipmapLevelAndCount, bias 1024 for negative levels), ResolutionLodBias, ClipmapCornerRelativeOffset (int2), ClipmapWorldOriginOffset (float3 origin relative to level center), LightSourceRadius, flags (UNCACHED, coarse level, receiver mask...). DEPTH: reversed-Z orthographic clip depth in [0,1] stored as 32-bit float in a uint physical pool texture (atomic-friendly); occlusion test 'occluderDepth > receiverDepth'; view-space Z reconstruction is linear: viewZ = (clipZ - _43)/_33. Receiver world pos is reconstructed from the scene depth buffer + camera matrices (deferred, translated-world), then rebased per level via DFFastLocalSubtractDemote(level PreViewTranslation, camera PreViewTranslation) — everything sample-side stays float32.

## Final filter & subsurface handling
FilterVirtualShadowMapSampleResult: after SMRT, add blue-noise dither of ±0.5/15 to ShadowFactor when it's in (NoiseScale/4, 1) — breaks 8-level banding from 7-ray averages; relies on TSR/TAA to resolve. Subsurface: light source radius inflated by (1-opacity)*SubsurfaceMinSourceRadius (min source angle 5°, cvar SubsurfaceShadowMinSourceAngle) and shadow factor converted via occluder distance (transmittance), which is why OccluderDistance is computed per ray. Backface cull: directional pixels facing >~5° + sourceRadius away from the light are shadowed without any tracing (IsBackfaceToDirectionalLight, MinSinAlpha=0.1).
