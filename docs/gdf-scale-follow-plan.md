# GDF 스케일링 재정의 계획서 (R0 ~ R3)

`docs/gdf-camera-follow-plan.md`(밀집 클립맵 추종)를 **대체**한다. 원안 검토 중 확인된
사실: 콘텐츠의 GDF 소비는 퍼-메시 직접 샘플 경로(`P11_DIRECT_SDF` 기본 ON, count==0)
이며 근접 해상도가 카메라와 무관한 퍼-메시 타일에서 나온다 — 밀집 클립맵의 파이너
레벨은 콘텐츠가 마치하지 않으므로, 카메라 추종의 진짜 대상은 **직접 경로가 실제로
의존하는 월드-고정 자원**이다:

1. **코어스 밀집 필드**(`SCENE_DIM=48³`, 씬 AABB 전체) — ms_geo의 빈-공간 스텝퍼이자
   미커버 공간의 폴백. 월드가 커지면 복셀이 조악해져 마치 품질/비용이 무너진다.
2. **씬 알베도**(48³, 씬 AABB 전체) — 퍼-메시 알베도 아틀라스 미적용 표면의 색 소스.
3. 인스턴스 셀 그리드는 `cbrt(n)` 캡 64로 이미 콘텐츠-비례 스케일 — R0에서 실측으로
   재확인만 한다(원안의 "그리드 카메라-중심화"는 실측이 요구할 때만).

방법론은 이번 세션에 검증된 토로이달 콘텐츠-창 패턴(GI `0360c08`)의 GDF판이며,
보관해 둔 원안 G0/G1 diff(64B 토로이드 행·슬랩 합성·`gdf_slab_write`)를 코어스
필드에 재적용한다.

## 1. 목표 / 비목표

**목표**
- 코어스 필드+씬 알베도를 **고정 월드 크기의 카메라-추종 토로이달 창**(기본 96 m —
  현 던전 스케일에서 오늘과 동일 복셀 밀도)으로 전환: 월드 크기와 무관한 근방 품질.
- 창 밖: 창 AABB까지의 해석적 박스 거리로 보수적 스텝(셀 그리드는 월드-앵커 유지라
  정확성 불변 — 원거리 마치가 느려질 뿐 틀리지 않는다).
- **실측 가능한 콘텐츠로 게이트**: 던전 제너레이터 대형 층(예 `--tiles 160` = 320 m)
  을 스트레스 픽스처로 추가 — R0의 전/후 수치가 트랙의 존재 이유를 증명해야 한다.
- 정적 카메라 = 재중심 없음 = 골든/PT 불변(세션 불변식 그대로).

**비목표**
- 인스턴스 셀 그리드/아틀라스 상주성 개편(R0 실측이 요구하면 별도 트랙).
- 파이너 밀집 클립맵 추종(대체된 원안 — `P11_DIRECT_SDF=0` 폴백 티어는 현행 유지).
- 스트리밍 레벨 로딩(별도 트랙; 이 트랙은 로드된 지오메트리 전제).

## 2. 설계

- **창**: `P11_GDF_WINDOW`(월드 미터, 기본 96; 0 = 현행 씬-AABB 고정 = 폴백 심).
  로드 시 카메라 중심, 씬 AABB보다 크면 자동 비활성(작은 레벨 = 현행과 동일 동작).
- **재중심**: 데드존(창의 1/4) 이탈 → arm → 다음 프레임 pre-graph 적용(2-페이즈,
  `0360c08` 패턴). 복셀 격자 스냅 → 정수 델타 → 토로이드 스크롤 갱신 + 새 행 슬랩만
  CPU 합성(`compose_sdf_slab` — 원안 diff 재사용) + `gdf_slab_write`로 토로이달
  기록. 알베도 슬랩은 퍼-메시 알베도 아틀라스가 있으면 그from 합성, 없으면 상수.
- **샘플링**: `mesh_sdf_sample.slang`의 `ms_dense`(+ 알베도 폴백 경로)에 토로이드
  행(정규화 스크롤+보더) 적용 — 헤더 버퍼에 행 추가, REPEAT 샘플러(`samp_wrap`).
  창 미포함 지점은 박스-거리 폴백. 헤더는 2-슬롯 호스트 링(descriptor 플립 패턴).
- **소비자 무접촉**: cm_/ms_ 시임 내부에서 완결 — AO/GI/반사/캐시 셰이더 무변경.
- **GI 볼륨과의 정합**: gv 트레이스가 ms_geo를 읽으므로 슬랩 패스를 그래프 최선두
  배치(gi_shift와 동일).

## 3. 마일스톤

- **R0 — 스트레스 픽스처+실측**: 던전 `--tiles N`(기본 40 유지) 추가, 160/240에서
  현행 수치 기록 — 코어스 복셀 크기, 로드 쿡 시간, 셀 그리드 점유 분포, AO/GI 캡처,
  프레임 비용. **이 수치가 개선을 증명 못 하면 트랙 중단**(정직 게이트).
- **R1 — 코어스 창 추종**: 헤더 토로이드 행 + ms_dense 창 샘플링 + 재중심/슬랩
  기계(diff 재적용) + 알베도 창. 게이트: 골든 byte-PASS(창=씬AABB 폴백/소형 레벨),
  160-타일 보행 시퀀스 프레임-델타(재중심 ≈ 인접), R0 대비 근방 AO/GI 개선 캡처.
- **R2 — 예산/폴리시**: 슬랩 비용 실측(재중심 프레임 스파이크 없음), 층 전환 전체
  재설치, DIAG 카운터, 기본 ON 판정(소형 레벨 자동 비활성이므로 저위험).
- **R3 — 검증/등록**: 골든+PT 정적 불변, 대형층 플레이, quality.rs 노브(창 크기),
  DX≡VK 배치, 메모리 원장.

## 4. 리스크

- **창 밖 마치 품질**: 원거리 레이가 박스-거리 폴백으로 스텝 수 증가 — R1에서
  PROFILE_GPU 실측, 필요시 창 밖 저해상 2차 창(비목표로 유지, 수치로만 재개).
- **대형층 제너레이터 전제**: procgen이 160+에서 방 배치를 유지하는지 R0에서 확인
  (파라미터 새니타이즈 확장 포함).
- **슬랩 합성 CPU**: 창 재중심 시 최대 창/4 행 — R0 실측이 게이트.
