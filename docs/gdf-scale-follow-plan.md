## 0. 레퍼런스 구조 요약 (research 노트의 결론)

- 오브젝트 스테이지(퍼-메시 SDF 아틀라스)는 월드-앵커 — **우리의 직접 샘플 경로가
  이미 이것**. 글로벌 필드는 거기서 파생되는 캐시다.
- 글로벌 필드 = **카메라 중심 4-레벨 클립맵**(지수 간격), **스파스 페이지**(페이지
  테이블 → 공유 페이지 아틀라스, wrap 트라이리니어), 토로이달 스크롤 + 슬랩 갱신.
- **정적/무버블 2-레이어 캐시**: 정적 레이어는 프레임 간 캐시, 무버블 레이어는 매
  프레임 더티-페이지 재합성 — 이동 오브젝트의 이중 풋프린트가 더티를 마킹.
- 합성은 GPU 컴퓨트(클립맵별 오브젝트 컬 → 그리드 → 페이지별 nearest-surface 합성).
- 원거리 스텝: 클립맵별 저해상 MIP(clamp), 근거리 정밀은 페이지 아틀라스.

우리 이점: VSM V1~V3가 같은 페이지 기계(테이블/프리리스트/2-레이어/이중 풋프린트)를
이미 검증했고, 인스턴스 테이블·퍼-메시 아틀라스·알베도 아틀라스가 GPU에 있다.

## 1. 목표 / 비목표

**목표**
- 밀집 48³ 씬 볼륨(+씬 알베도)을 레퍼런스형 글로벌 필드로 대체: 4-레벨 카메라 클립맵,
  페이지-스파스, GPU 합성, 토로이달 스크롤, 정적/무버블 2-레이어.
- **동적 오브젝트가 필드에 들어간다**(상시 디렉티브): 리지드 무버(문/소품/횃불 등)의
  이동이 GI/AO/반사에 그 프레임 반영 — R3 리스크("동적 GI 부재")의 GDF 절반 해소.
- 소비자 시임 유지: ms_geo/cm_geo 입구 뒤에서 교체 — AO/GI/반사/캐시 셰이더 무접촉.
- 갤러리/골든 불변: 글로벌 필드는 콘텐츠 전용(`P11_GDF_GLOBAL`), 갤러리는 레거시
  밀집 앵커 유지.

**비목표(순서 기록)**
- 캐릭터(스키닝) 프록시 편입 — 캡슐 프록시 별도 트랙.
- 하이트필드/랜드스케이프 합성(해당 콘텐츠 없음).
- 스트리밍 레벨 상주성(별도 트랙).

## 2. 마일스톤

- **U0 — 스킴+자원**: 클립맵 플래너(4레벨, 지수 간격, 페이지 스냅), 페이지 아틀라스
  볼륨/테이블/프리리스트 할당, 인스턴스 테이블의 프레임별 업로드 경로(동적 전제),
  스트레스 픽스처(`--tiles`) — 실측 기준선. 소비자 미접속.
- **U1 — GPU 컬+합성, 밀집-페이지 브링업**: 클립맵별 오브젝트 컬 CS → 페이지 합성 CS
  (nearest-surface-wins, 알베도 동시), 전 페이지 밀집 할당(스파스는 U3), 토로이달
  스크롤(신규 페이지만 재합성), `P11_GDF_GLOBAL=1`에서 ms_dense 대체 샘플러(페이지
  테이블 경유, wrap). 게이트: 골든 불변(OFF 기본), 대형층 근방 품질 = 소형층과 동일
  캡처 증명, 보행 시퀀스 델타.
- **U2 — 동적 2-레이어**: 인스턴스 transform diff → 이중 풋프린트 더티 페이지,
  무버블 레이어 매 프레임 재합성 + 정적 레이어 캐시(스크롤/무효화时만), 병합 규칙.
  게이트: 무버 이동 시 재합성 페이지 수 로그(예산 내), GI/AO 반응 캡처, 정지 씬
  바이트 불변.
- **U3 — 스파스+MIP+편입**: 점유 기반 페이지 할당/회수(프리리스트 — VSM 교훈 적용),
  클립맵 MIP(원거리 스텝), quality.rs 티어, 기본 ON 판정, 골든+PT 배터리, DX≡VK
  배치 등록, 레거시 밀집 경로는 갤러리 앵커+폴백 심으로 유지.

## 3. 리스크

- **기계 규모**: VSM급 서브시스템 — 증분마다 골든/보행 게이트로 착지 확인, 마일스톤
  단위 커밋(중단 가능 지점 유지).
- **합성 비용**: 121 인스턴스 소형층은 자명; 대형층(수백 인스턴스 × 4레벨)의 페이지
  합성/컬 비용은 U1 PROFILE_GPU 게이트.
- **f16 아틀라스 정밀도 × 글로벌 min 합성**: dist_scale 경유 재스케일 누적 — U1에서
  PT 잔차로 검증(F2 S2b 선례).
- **2-레이어 병합 규칙**: min()은 무버 제거 시 정적 복원 필요 → 무버블 레이어는
  더티-클리어 후 재합성(캐시 아님)이 정답(레퍼런스 동일).
