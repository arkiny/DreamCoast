# VSM 페이지 캐시 부활 계획서 (R0 ~ R3)

V2 페이지 캐시는 실전에서 **한 번도 가동된 적이 없었다**: V3 무효화 구 수집
루프의 `VSM_MAX_INVAL` 선제 캡이 그리디 병합(리그→~1구, 정확히 이를 위해 추가)
**앞에서** 발화해, 캐릭터 리그(60+ 파트)가 있는 모든 프레임이 전체 무효화로
강등됐다(실측: 레벨 리베이스 27,794/28,152 프레임, 페이지 재렌더 ~92/프레임 —
설계 계약은 정지 시 ~0). 캡 순서를 고친 36ce05c는 옳지만, 캐시가 처음 켜지자
**캐시 유지 경로의 잠재 결함**이 노출됐다(윈도우드에서 페이지 블록 단위 회백/검정
대형 깨짐 — DIAG_SHOT_EVERY 자동샷 실증) → bee4b4e로 리버트된 상태다. 이
계획은 결함을 계측으로 규명한 뒤 캐시를 정식 복원한다. 이득: 페이지 재렌더
92→11/프레임(36ce05c 실측), vsm 래스터/페이지 비용 대폭 절감.

## 0. 구조 결정

- **검증은 윈도우드가 게이트**: 헤드리스 캡처는 프레임마다 GPU를 대기해 이
  결함 부류(프레임 중첩·상태 축적)를 구조적으로 숨긴다(오늘 세션의 반복 교훈).
  게이트 배터리 = `DIAG_SHOT_EVERY=<n>` 자동샷 + DIAG_FRAME_CSV(col5 pages:
  정지 시 ~0 계약 / col8 vsm_fallback: ~0 계약) 장기 배회 프로브.
- **통계를 먼저 신뢰 가능하게**: 현재 pages/overflow 판독은 무동기 readback이라
  수치가 오염된다(0/부분값 블립). 카운터를 GPU가 per-FIF consts diag tail로
  복사(코어스 폴백 카운터와 같은 FIF-세이프 하베스트 패턴)해 **프레임 정확**
  통계를 만든 뒤 수사한다 — 계약 위반(정지 시 pages>0)을 상시 감지 가능해진다.
- **의심 경로와 구조적 대안**: 유력 후보는 "스크롤 델타의 증분 체인" — csUpdate가
  meta 주소를 매 프레임 `page - scroll` 로 재기록하는데, 프레임이 드랍/중단되면
  (스왑체인 recreate, wait_idle 리빌드, 캡처 프레임) CPU 상태만 전진해 어긋난다.
  근본 대안 = **절대 주소화**: meta에 레벨-절대 페이지 좌표를 저장하고, consts에
  각 레벨의 절대 원점(페이지 공간)을 실어 csUpdate가 `절대좌표 - 절대원점`으로
  창-상대 주소를 **매 프레임 재유도**한다. 증분 체인이 사라지므로 드랍 프레임
  부류 전체가 무해해진다(레이스가 아니라 상태 설계의 수리).
- 두 번째 후보(depth-pin 좌표 유지, FIF 경계)는 R2의 계측이 판정한다.

## 1. 마일스톤

- **R0 — 신뢰 통계**: 카운터 → consts diag tail GPU 복사 + 하베스트 + CSV 갱신
  (pages/ovf가 FIF-지연 정확값이 됨). 게이트: 정지 헤드리스에서 pages=0 계약
  확인, 골든 불변(계측은 이미지 무관).
- **R1 — 절대 주소화**: meta/consts를 절대 페이지 좌표 체계로 전환(csUpdate·
  csAlloc·csClear + vsm.rs 인코딩). 캐시는 아직 꺼진 채(리버트 상태) 랜딩 —
  전체 무효화 하에선 동작 동일하므로 골든·실플레이 무위험. 게이트: 골든
  byte-PASS + 윈도우드 배회 프로브 이상 무.
- **R2 — 캐시 재점화**: 36ce05c 재적용(캡을 병합 뒤로). 윈도우드 배터리로 검증:
  ①정지 60 s: pages ~0 계약 ②배회 10 분: 자동샷 전수 눈검사(블록 깨짐 0) +
  vsm_fallback ~0 ③층 전환 10회(스왑체인/리빌드 경로 교차) ④그림자 diff 앵커
  (17b66df의 0.0065 기준). 실패 시: 자동샷이 잡은 깨짐 프레임 ↔ R0 통계로
  잔여 결함 국소화(depth-pin/FIF 후보 순).
- **R3 — 봉인**: 원장/문서 갱신, DX≡VK 등록(레이아웃 변경: meta·consts), 티어
  영향 확인(quality.rs), 커밋.

## 2. 리스크

- **절대 좌표 비트폭**: meta의 packed 주소(level 4b + page 14b×2)는 창-상대
  전제. 절대 좌표는 i64 페이지 인덱스 — packed 32b에 담으려면 **레벨 절대
  원점과의 차만 wrap 저장**(절대 원점을 consts에 i32로 실으면 차는 항상
  ±TABLE_DIM 이내) 형태로 설계해 스토리지 불변 유지.
- **성능**: 절대화로 csUpdate에 산술 몇 개 추가 — 페이지당 O(1), 무시 가능.
- **재발 대비**: R2 배터리가 실패해도 R0(통계)·R1(절대화)은 독립 가치로 잔존,
  캐시는 계속 꺼진 안전 상태를 유지한다.

## 3. 게이트 요약

golden byte-PASS · clippy -D warnings · 윈도우드 배터리(자동샷 + 신뢰 통계
계약: 정지 pages~0, fallback~0, 블록 깨짐 0) · DX≡VK 원장 등록 · 무거운 작업
1개씩.

## 4. 결과 (R0~R2 랜딩, 2026-08-11)

- **R0 `eade203`**: csStats → per-FIF consts diag tail 스냅샷. 무동기 readback의 유령
  붕괴 블립 소멸(윈도우드 프로브 min 113, 블립 0). `stats()`는 하베스트 값 반환.
- **R1 `8aeaec8e`**: 절대 페이지 주소화(meta=절대 wrapped 14b, consts=절대 원점,
  매 프레임 모듈러 재유도). 증분 델타 체인 폐지 — 드랍 프레임 구조적 무해화.
- **R2 `5822e28b`**: 캡-순서 수정 재적용. 정지 pages 92~116→**8**, 배회 12~38.
- **+`0dd5d038`**: V2-원죄 **Y 슬라이드 부호 버그** — 텍셀 Y는 광원-up 반전인데 양
  축에 X 부호를 적용, 캐시가 죽어있어 랜딩 이래 도달 불가였던 잠재 결함. 절대
  매핑의 Y를 반대 부호로 접어 수리(지붕 위 거대 그림자 다각형의 정체).
- **+`f60b504b`**: **무효화 에포크 절대화** — 1회성 플래그가 핫스왑 스톨 프레임에
  삼켜져 이전 층 그림자가 새 층에 생존하던 것을, 레벨 에포크 vs 페이지 출생
  에포크 매 프레임 비교로 대체.
- 유저 필드 확인: 배회·층 연속 하강 정상. 교훈 2건은 vsm-junction-leak 원장 참조
  ("한 번도 실행 안 된 경로의 게이트 통과는 무의미", "지붕 위 그림자 = 공짜 불변량").

## 5. DX≡VK 등록 (Windows 검증 항목)

- consts scroll 시맨틱 변경(xy=절대 원점 wrapped, w=에포크) + meta [12] 에포크 사용.
- csStats 신설(vsm_stats_cs) + diag tail 16 B 확장(VSM_CONST_SIZE +16).
- Y 부호 접기(csUpdate/csAlloc) — 백엔드 중립 산술이나 캐시 슬라이드의 실거동은
  Windows에서 배회+층 하강 배터리로 재확인할 것(직렬 캡처는 이 부류를 숨김).
- 레벨 디더 밴드(adeedd9, pbr/vsm_pages) — 원경 스펙클 관찰 항목 포함.
