# 게임 UI 계획서 (M-U0 ~ M-U3)

`docs/game-framework-plan.md` §6 이연 순서의 다음 항목: **게임 UI**. 현 상태는 dev
ImGui 창("Dungeon" 디버그 패널)에 HP 바/포션/층 정보가 얹혀 있고, 이는 개발 오버레이의
외형이지 게임의 HUD가 아니다. 이 트랙은 프로덕션 HUD·오버레이·메뉴 레이어를 게임
프레임워크의 일부로 만든다.

## 0. 구조 결정 (reference engine 대응)

레퍼런스 엔진의 UI는 위젯 트리 → 페인트 → **배치드 2D 드로우리스트**(클립 사각형 +
텍스처드 쿼드 + 폰트 아틀라스) 파이프라인이다. 우리 엔진에는 그 최하층이 이미 검증돼
있다: `crates/gui`의 렌더 경로(정점/인덱스 블롭 연결, per-command 클립, 바인드리스
텍스처, 프레임-링 버퍼)가 정확히 그 드로우리스트 소비자다. 따라서:

- **드로우 레이어는 재사용**: 창 없는 **background/foreground 드로우리스트**로 HUD를
  합성한다(창 chrome 제거 = 외형 문제의 근원 제거). 새 렌더 패스·새 크레이트 없음.
- **HUD API는 즉시 모드**(게임이 이미 그렇게 쓰고 있고, 상태는 전부 게임 시뮬에 있음).
  리테인드 위젯 트리는 **메뉴 규모가 요구하는 최소형**(포커스 + 버튼 목록)만 M-U3에서
  도입 — 전면 위젯 시스템은 콘텐츠(인벤토리/설정 화면)가 생길 때의 별도 트랙.
- **표현 전용 계약**: HUD는 시뮬 상태를 읽기만 한다(fixed_update 결정성 불변).
  훅 미설치 경로의 byte-identity(hooks.rs의 랜딩 계약)는 그대로 유지된다.

## 1. 마일스톤

- **M-U0 — HUD 컴포지터 (창 제거) ✅**: `apps/dungeon/src/hud.rs` 신설.
  - 플레이어 HP 바(하단 좌): 배경/채움/최근-피해 고스트(짧은 지연 후 따라붙는 밝은
    띠 — FIXED_DT 스텝 기반, 결정적) 3층, 기존 녹→황→적 규칙 유지.
  - 포션 pip(플라스크 실루엣 폴리곤, 보유/최대 + 층 잔여), 층·시드 라벨(상단 좌),
    피격 테두리 펄스(피격 프레임 기반 감쇠).
  - 사망 오버레이(풀스크린 딤 + 타이틀 + 재시작 안내), 층 전환 배너/페이드(기존
    전환 상태머신 표기).
  - 디버그 패널("Dungeon" 창 + 성능/조작 도움말)은 `DUNGEON_DEBUG_UI=1` 토글로 이동.
  - 게이트: 상태별 헤드리스 캡처(생존/부상/사망/전환, DUNGEON_HOLD/TAP 레시피) 결정적
    재현 + gallery/sponza 골든 불변(훅 경로 밖).
- **M-U1 — 월드 앵커 ✅**: 그런트 오버헤드 HP 바(전투 관여 시 표시, 이탈 후 페이드) +
  처치 확인 표시. 투영은 게임 측에서 재구성(camera 훅이 pose+fov를 이미 소유; 스크린
  x/y는 near/far 무관이므로 엔진 시임 변경 없음). 게이트: 전투 시퀀스 캡처.
- **M-U2 — 게임 서체 ✅ (Alegreya SC 임베드, 4사이즈 아틀라스 — DPI는 베이크 사이즈 선택)**: OFL(SIL Open Font License) 서체 1종 임베드, imgui 폰트
  아틀라스에 2사이즈(HUD 본문/타이틀) 로드. OFL은 임베드·재배포 허용 — 폰트 파일과
  라이선스 사본을 리포에 두고 `THIRD_PARTY_LICENSES.md`에 등재(오디오 트랙의 cpal
  등재와 같은 절차). 폴백(품질 미달 시): 자체 픽셀 폰트(라이선스 제로). 게이트:
  캡처 + 등재 확인.
- **M-U3 — 메뉴/입력 라우팅 ✅ (+플랫폼 close_on_escape 시임: 훅 게임은 Esc 소유)**: 일시정지(Esc: resume/restart/quit-to-desktop),
  게임오버 화면에 재시작 버튼 통합, UI 활성 시 게임 입력 차단(`want_capture` 위임),
  키보드 포커스 최소 모델(위/아래/확인). **pause = 시뮬 스텝 소비 중단**(fixed
  accumulator 규칙에 명시적 게이트) — 표현 전용 계약 유지. 게이트: 인터랙티브 스모크
  + 캡처 결정성 불변.

## 2. 라이선스

- 신규 코드 의존성 **없음**(imgui/imgui-sys는 기존 MIT). 신규 자산 = OFL 폰트 1종:
  폰트 본문 + OFL 사본 리포 동반, `THIRD_PARTY_LICENSES.md`에 항목 추가.

## 3. 리스크

- **sRGB/톤맵**: HUD는 기존 imgui 패스(톤맵 후 백버스퍼)와 같은 지점에 그려지므로
  색 공간 거동 무변화.
- **결정성**: 고스트 바·펄스·페이드는 전부 FIXED_DT 스텝 카운트 기반(경과 실시간
  금지) — 캡처 골든이 게이트.
- **창 제거 회귀**: 디버그 패널은 삭제가 아니라 토글 이동 — 개발 워크플로 유지.
- **폰트 아틀라스 재빌드**: 폰트 추가는 Gui 생성 시 1회(런타임 재빌드 없음) —
  로딩 경로 비용만.
