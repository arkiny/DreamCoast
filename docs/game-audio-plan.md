# 게임 오디오 트랙 계획서 (M-A0 ~ M-A3)

`docs/game-framework-plan.md` §6 이연 순서의 첫 항목: **오디오 크레이트(cpal 믹서 + SFX)**.
게임 트랙 디렉티브(재사용 가능한 프로덕션 코드, per-scene 유틸리티 금지)와 엔진 규칙
(단일 소스, 결정성, opt-in 시임)을 오디오에 그대로 적용한다.

## 1. 목표 / 비목표

**목표 (v1)**
- 엔진 크레이트 `crates/audio`(`dreamcoast-audio`): 어느 게임이든 쓰는 범용 믹서 —
  던전 크롤러는 첫 소비자일 뿐이다.
- 던전 크롤러의 코어 루프 사운드: 발소리(지면), 검 휘두름/명중, 그런트 피격/사망,
  포션 픽업/음용, 층 전환, 횃불 크래클 루프.
- 탑다운 공간감: 리스너 = 플레이어, 거리 감쇠 + 스테레오 팬.
- **결정적 오프라인 렌더 모드**: 디바이스 없이 N 샘플을 믹스해 해시하는 유닛테스트 —
  믹서는 순수 DSP이므로 골든-이미지와 같은 급의 게이트를 오디오에도 세운다.

**비목표 (v1 범위 밖, 순서만 기록)**
- HRTF/바이노럴, 컨볼루션 리버브, 오디오 스트리밍(전부 메모리 상주), 미들웨어 연동.
- 음악 시스템(앰비언스 베드까지만; 인터랙티브 뮤직은 별도 페이즈).
- 도플러/오클루전(SDF 기반 오디오 오클루전은 흥미롭지만 별도 페이즈로).

## 2. 아키텍처

```
game (fixed_update)          audio thread (cpal callback)
  AudioSystem::play(..) ─┐
  AudioSystem::set_listener┼─ SPSC command ring ──> Mixer::render(&mut [f32])
  (이미터 위치 갱신)      ─┘   (락프리, 무할당)        voices[N] → bus → master
```

- **디바이스 계층**: cpal 출력 스트림(플랫폼 기본 디바이스, f32 인터리브드 스테레오).
  디바이스가 없거나 열기 실패(CI/headless) → **Null 싱크 폴백**(콜백만 무음 소비) —
  게임/캡처 경로는 오디오 유무와 무관하게 동일하게 동작한다.
- **믹서**: 콜백 스레드에서만 상태 소유. 보이스 = {버퍼 id, 재생 커서, 게인, 팬, 루프,
  이미터 위치(선택)}. 커맨드 링(SPSC)으로만 통신 — 콜백 안 무할당·무락 불변식.
  샘플레이트는 **쿡 시점에 48 kHz로 고정**(런타임 리샘플링 없음; 디바이스가 48 kHz가
  아니면 스트림 요청으로 협상, 실패 시 선형 리샘플 1단만 허용하고 로그).
- **공간화 v1**: 게인 = `1 / (1 + (d/r)^2)` 꼴의 range 기반 감쇠(라이트의
  `point_attenuation`과 별개 상수 — 도메인이 다르므로 복제 아님, 오디오 크레이트가
  단일 소스), 팬 = 리스너 기준 좌우 성분의 등파워(√) 팬 법칙.
- **버스**: SFX / Ambience / Master 3단 게인. v1 덕킹 없음.
- **보이스 정책**: 상한 32, 초과 시 최약(거리×게인) 보이스 스틸. 동일 SFX 스팸 방지
  쿨다운(ms)은 게임 측 정책으로 게임 크레이트에.

### SFX 에셋: 프로시저럴 신스 우선

릭/클립과 같은 원칙(시드 결정적 생성, 외부 에셋 무의존, 라이선스 클린):
- `dreamcoast-audio::synth` — 순수 f32 DSP 프리미티브(노이즈 버스트, 지수 감쇠 엔벨로프,
  상태변수 필터, 피치 스윕)로 SFX를 **시드 결정적으로 합성**해 48 kHz 모노 버퍼 생성.
  발소리 = 필터드 노이즈 탭, 스윙 = 대역 스윕 노이즈(우퍼시), 명중 = 저역 임팩트+노이즈,
  포션 = 사인 글리스 등 — 레트로가 아니라 폴리(foley) 지향 파라미터로.
- 합성은 로드 시 1회, 콘텐츠 해시 쿡캐시(`cache/generated/` 경유가 아니라 메모리 생성 +
  버전 상수 — 수 ms 수준이라 쿡 파일이 과설계면 생략, M-A1에서 실측 후 결정).
- **AI 오소링 .wav 시임**: `assets/audio/*.wav`가 존재하면 같은 id의 프로시저럴 버퍼를
  대체(48 kHz 모노로 쿡). 에셋은 gitignored + fetch 스크립트 — 릭과 동일한 운용.

### 게임 통합 시임

- `GameConfig`에 오디오 켜기(기본 on, `NO_AUDIO=1` 시임)와 `AudioSystem` 핸들 주입.
  훅 시그니처는 변경하지 않는다 — 게임 구현체가 핸들을 소유하고 `fixed_update`에서
  직접 `play/set_listener/set_emitter`를 호출(입력 스냅샷과 같은 계약: 테스트에서
  Null 싱크로 전 구간 구동 가능).
- 헤드리스 캡처(`--screenshot*`)는 Null 싱크 강제 — 골든 경로 부작용 제로.

## 3. 마일스톤

- **M-A0 — 크레이트 브링업**: `crates/audio` + cpal 디바이스/Null 싱크 + SPSC 링 +
  믹서 코어(보이스/게인/팬/루프) + 디버그 테스트 톤(`AUDIO_TEST=1`, 사인 440).
  게이트: 오프라인 렌더 유닛테스트(믹스 N 샘플 해시 — 팬 법칙/루프 경계/보이스 스틸),
  맥 실기 톤 확인, `NO_AUDIO`/Null 경로에서 골든 배터리 불변.
- **M-A1 — 프로시저럴 SFX 뱅크**: synth 프리미티브 + 던전 SFX 8종 합성, id 레지스트리.
  게이트: 합성 결정성 유닛테스트(시드→버퍼 해시, 플랫폼 간 f32 재현성 리스크는 자체
  구현 수식만 사용해 회피 — libm 경유 초월함수 금지, 다항 근사 자체 구현), 청감 확인.
- **M-A2 — 게임 배선**: 리스너=플레이어, 전투/이동/아이템 이벤트에 SFX, 횃불 크래클
  루프(이미터 = 레벨 횃불 엔티티, 거리 감쇠 실측), 층 전환 사운드.
  게이트: 플레이테스트 + Null 싱크 헤드리스에서 시뮬 결정성 불변(입력 시퀀스 재현).
- **M-A3 — 버스/폴리시**: SFX/Ambience/Master 게인, 앰비언스 베드(저역 룸톤 루프),
  보이스 상한/스틸 실측, 볼륨 env 시임(`AUDIO_MASTER=0.8` 등).
  게이트: 32 보이스 스팸 스트레스에서 xrun/글리치 없음(콜백 시간 로그), 청감 확인.

## 4. 리스크

- **cpal 의존 추가**: 워크스페이스 최초 오디오 외부 크레이트(계획서 §6 원안에 명시된
  선택). 크로스플랫폼(CoreAudio/WASAPI/ALSA)을 직접 치는 비용 대비 승인 전제.
- **콜백 실시간성**: 무할당·무락 불변식을 링 설계로 강제; 버퍼 언더런은 카운터로 노출
  (`DIAG_AUDIO=1` 1회 경고 — DIAG_SLOTS 패턴).
- **디바이스 협상**: 48 kHz 미지원 디바이스(드묾) → 1단 선형 리샘플 + 로그. 디바이스
  핫스왑(이어폰 분리)은 v1 스트림 재생성으로 수용(끊김 허용).
- **결정성**: cpal 경유 실출력은 검증 대상이 아님 — 결정성 게이트는 전부 오프라인
  렌더(합성+믹스)에만 건다.

## 5. 검증 규약

- 유닛: 합성 해시, 믹스 해시, 팬/감쇠 수치, 링 오버플로 동작.
- 통합: `CAPTURE_SEQ + DUNGEON_HOLD` 경로가 Null 싱크에서 기존과 바이트 동일(오디오는
  렌더 경로 무접촉 — 골든 배터리가 간섭 검출).
- 실기: 맥에서 청감 + `PROFILE`류 콜백 타이밍 로그. Windows(WASAPI)는 DX≡VK 배치에 편승.
