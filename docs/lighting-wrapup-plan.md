## 0. 결론 요약

**충실도(PT 잔차)·견고성(결정론) 축은 봉인 완료 상태다.** 마무리를 실질적으로 막는 미결은
단 하나 — **F6O 증분2(스카이라이트 재캘리브)를 수행해 픽셀당 sky-vis(`P_SKYVIS_PP`)의 기본
ON/OFF 판정을 내리는 것**이다. 나머지는 전부 (i) bounded 위생, (ii) 문서화된 deferral,
(iii) 외부 의존(Windows 동결)으로 분류된다.

권장 마무리 범위: **A(필수) = 증분2 판정 + knob 처분 원장 + 문서 봉인, 집중 4–6일.**
B(선택, 각각 중단 조건 내장) 포함 시 5–7일. C는 재개 조건이 명시된 deferral로 종결 문서에 등재.

## 2. 마무리 선(finish line) — 수용 기준 5조

"라이팅 마무리됨" = 아래 동시 충족:

1. **게이트 ALL PASS** — 최종 커밋 기준 전체 배터리 재확인. 예산은 하향-전용 래칫 봉인(상향
   재기준선은 F6M류 레퍼런스-측 변경 사유가 문서화될 때만).
2. **열린 knob 전면 처분** — pending 상태의 모든 knob이 **(a) 기본 ON 랜딩**(게이트
   improved-or-neutral 실증+래칫) / **(b) 옵트인 봉인**(히어로·진단 전용, 재개 조건 1줄) /
   **(c) 재시도-금지 원장 등재** 중 하나로 분류. "결정 미기록" 0건.
3. **문서 봉인** — 로드맵 §3/§4b 최신화(F1/F4 ✅, F6 아크 종결), wrap-up 종결 문서 1편:
   도달점·knob 처분표·재개 조건 원장·**게이트 커버리지 공백 원장(6축+각 재개 조건 1줄)**·
   스테일 정정 2건·DX≡VK 누적 배치 목록.
4. **알려진 시각 결함의 처분 기록** — 각 잔여 결함(직교-개구 암전, 커튼 글로우 부재, 프로브-격자
   잔여 얼룩, TAAU speckle, fine 뷰-의존)이 "수리됨 / C-트랙 위임(재개 조건 명시) / 레퍼런스
   정합권(결함 아님)" 중 하나로 귀속 — F6I §0의 "출하 수용" 선택지를 공식 행사하는 절차.
5. **히어로 산출물 최신** — level.rs 단일소스 레시피가 최종 knob 상태와 정합, 히어로 스틸은
   **최종 커밋 기준 1회** 재캡처(중간 캡처 금지 — B3가 히어로 knob에 배선되므로 순서 주의).

**DX≡VK Windows 검증은 마무리 선에서 명시 제외**(외부 의존 동결 — 누적 배치 원장 등재까지가
wrap-up 몫).

## 3. 작업 분류

### A. 마무리 필수

**A1. F6O 증분2 — 스카이라이트 재캘리브 + `P_SKYVIS_PP` 기본 판정.** *예상 2–4일.*

- **왜 필수**: 이것 없이 봉인하면 검증 완료된 근본 수리가 진단-전용으로 남고, 크러치-캘리브
  (sky_gain 6.0 = 붕괴-V 적합, F6H 실측)가 출하 기본으로 고정된다. build-to-quality 지시와
  정면 충돌. 핵심은 **판정을 내리는 것**이지 "기본 ON"이 아니다 — 악화 판정도 유효한 착지.
- **스윕 범위 울타리(사전 등록)**: 조정 대상은 **tint / min_occ / sky_gain 3종 + PP on/off뿐**.
  PP의 N(레이 수)/reach/denoise 파라미터는 스윕 대상 아님(F6O §2b — 게이트·PROFILE_GPU로만
  결정). **tint knob의 디퍼드/볼륨 2원화(two-tint)는 wrap-up 범위 밖**(새 phase-doc 사안) —
  스윕 공간 내 improved-or-neutral 점이 없으면 자동으로 옵트인 봉인이 착지다.
- **러너 예산(사전 등록)**: coarse-to-fine 프루닝 — ① PP=ON 단독 A/B(현 캘리브, 방향 확인) →
  ② tint 4점(0.15/0.145/0.12/0.10, PP=ON 고정) → ③ 최적 tint에서만 min_occ·sky_gain 미세 →
  ④ 최종 후보에서 PP=OFF 역회귀 1회(볼륨-V 소비자 회귀 감시) + B1 arm. **총 러너 상한 15회** —
  초과 시 옵트인 봉인 판정으로 종료.
- **기본 ON 판정 기준(3중, 전부 필수)**:
  1. **block64 양 게이트 improved-or-neutral**(같은-설정 쌍: AUTO_EXPOSURE=1, RENDER_SCALE=1,
     WARMUP 192).
  2. **성능 수용** — 티어별 프레임 예산 내(fence-wait 델타, PROFILE_GPU 실측; `P_SKYVIS_DIV`
     티어값 명시). 화질 중립·성능 회귀 조합의 기본 ON 금지. 성능 초과 시 사전 등록된 분기:
     **티어별 기본(예: High만 ON)** 또는 옵트인 봉인.
  3. **티어-res 수동 프로토콜 병행** — PT 게이트는 RS=1이라 티어-res 거동에 맹목이므로, F6O
     §2b 시각 프로토콜(근/원 부조 A/B, 매칭 EV11 블록-소멸, DEBUG_VIEW=8) 재수행 +
     CAPTURE_SEQ 정적 셔머로 시간-누적 아티팩트 확인.
- **원자적 착지(사전 등록)**: 악화/공집합 판정 시 `P_SKYVIS_PP`=OFF뿐 아니라 **tint/min_occ/
  sky_gain 기본값도 봉인값(t 0.15 / 현행 / 6.0)으로 전량 복귀**. 재캘리브 값은 PP=ON 착지에만
  결합해 랜딩. 볼륨-V 경로 단독의 tint 하향은 F6G가 실측 기각한 창(t<~0.145 sunlit 차단)의
  재시도라 **부분 랜딩 금지**.
- **볼륨-V 소비자 감시(수치화)**: 기존 PT 캡처 내 반사·캐시 기여가 지배적인 크롭 1–2개를 사전
  지정, rt-compare 크롭 평균을 arm별 섀도 지표로 원장에 기록(신규 게이트 아님 — 기존 도구).
  sc_viz 육안 확인 병행.
- **상쇄-착지 귀속**: 총량 정합+스펙트럼(Δ(B−R)) 오프 = 상쇄 의심 → **EV11 고정 항별
  오라클(P8_PT_VVIEW/EVIEW, DEBUG_VIEW=15 raw E)로 귀속 후 진행. block64 단독 판정
  금지**(F6I §0 판독 규칙, F6O §4).
- **히어로 knob**: 증분2 창에서는 `P_SKYVIS_BENT_FLOOR=0.25` **히어로 레시피 값 재검증만**
  수행(F6O §0.5-6이 증분2 범위로 명시). `P_GDF_FACING_FLIP` 기본화 재심은 **하지 않음** —
  재개 조건(F6M §2c: 점유 트랙 결합 재캘리브 또는 PT 반투명 정직화)이 증분2와 무관하므로
  전제 미충족 재시도가 된다. A2 원장에서 (b) 옵트인 봉인으로 처분.

**A2. Knob 처분 원장 확정.** *예상 반나절(문서).*

A1 판정 후 전 knob을 (a)/(b)/(c)로 분류. 대부분 사실상 결정돼 있고 기록만 없다:
- `P_SDF_OPEN_UNSIGNED` → (c) F6I §0 봉인. `P_GI_SUN_HARDVIS` → (b) — F6F가 태양-디스크 유도
  k≈50 페넘브라로 원 사유(각반경-정합)를 기본 경로에서 해소, knob은 진단 봉인.
- `P_GDF_FACING_FLIP` → (b) 히어로 옵트인, 재개 = 점유 트랙 결합 재캘리브 또는 PT 반투명
  정직화(F6M §2c 원문). `P_GI_TRAPPED_FILL` → B1 결과에 따라 (a)/(b).
- `P_TAAU_ANTIFLICKER` → (b) 옵트인 봉인 + 재개 조건 = **티어-res 셔머/HF 게이트 신설**(C-표
  이관 — §3 C). 게이트 없는 기본 플립 금지 선례 준수.
- `P_SKYVIS_TINT_V0` → (b) 재개 조건 = 픽셀당-V 시대 재판정. `P_GI_FINE_HALF` → (b) 파생 기본
  7.25m이 양 게이트 국소 최적(F4B3 실측) — 원장 기록만.

**A3. 문서 봉인 + 최종 배터리.** *예상 1일.*

로드맵 §3/§4b 최신화, wrap-up 종결 문서(§2 조건 3의 산출물 전부 — 커버리지 공백 원장·스테일
정정·F6M T2 처분[점유 트랙의 α-가중 위트니스가 대체 예정이라 독립 측정 가치 낮음, 자연 소멸]·
반투명 2트랙 구분[F6M 라이팅-충실도 트랙 vs Phase 20 라스터 확장, translucency-pass.md §4-6] 포함),
스테일 로컬 브랜치 정리, **최종 커밋에서 전체 배터리 1회 ALL PASS 후 push**.

### B. 선택 (bounded — 중단 조건 내장, A1 판정을 지연시키지 않는 것이 공통 원칙)

- **B1. `P_GI_TRAPPED_FILL` arm의 증분2 편입.** A1 스윕 ④에서 최적 후보 캘리브 위에 1 arm.
  개별 게이트 회귀 시 즉시 분리·옵트인 봉인(F6H/F6M "물리 수리가 크러치 개방" 클래스 — 본체와
  묶어 재협상 금지). F6M T2(하드-블랙 폴백 디커플 측정)는 **수행하지 않음**(점유 트랙 이관).
- **B2. gdf_reflect 법선 플립 이식.** *반나절.* diffuse 판(gdf_gi bit2/gdf_ao bit1)과 동일
  계약, knob 기본 OFF라 기본 경로 불변. 골든 바이트-불변 깨지거나 반나절 초과 시 중단·점유
  트랙 배치 이관. **랜딩 시 히어로 재캡처는 아직 하지 않음**(§2 조건 5 — 최종 1회).
- **B3. 레거시-마치 위생(sky 0.25 하드코드 + Apple 노브 기아 — 동일 태스크).** *반나절.*
  **0번째 스텝: 갤러리 config에서 해당 경로 liveness를 grep/실측으로 확인** — 갤러리 프리셋
  (P_GI_VOLUME OFF)이 레거시 마치를 밟아 바이트-앵커에 살아 있으면 즉시 중단·C 이관(위생이
  앵커 재베이스를 정당화하지 않음). 볼륨-온리 출하 확정이면 둘 다 데드코드 정리로 대체하되,

## 4. 실행 순서

전제: 러너 1회 ~20분(ptcache 유효). ptcache 무효화 회피가 총 소요를 지배 — sky_gain을 건드리는
행만 `--pt-refresh`(또는 env 명시 전달로 캐시 키 분리) 필수.

1. **0단계 — 착수 스냅샷** *(0.5h)*: 현 main 배터리 1회 ALL PASS 기준선 고정, ptcache 온전 확인.
2. **1단계 — A1 증분2 스윕** *(2–3일, 러너 상한 15회)*: §3 A1의 프루닝 순서·판정 기준·원자적
   착지 그대로. `--update`는 **최종 판정 1회만**(중간 실행 = 그 시점 값이 새 천장이 되는 사고).
   기본 경로 변경 시 sc_viz/gdf_ao 재시드 + 'Compiling dreamcoast-shader' 확인(스테일-셰이더 함정).
3. **2단계 — B 항목** *(0–2일, 선택)*: B1(스윕 창 내 arm) → B2 → B3 → B4. 각 항목 후 배터리
   1회. 중단 조건 발동 시 원장 처리 후 다음으로.
4. **3단계 — A2+A3 봉인** *(1일)*: knob 처분표 → 로드맵 최신화 + 종결 문서 → 브랜치 위생 →
   **level.rs 히어로 레시피 갱신 + 히어로 재캡처(최종 커밋 기준 1회)** → 전체 배터리 ALL PASS
   → push.

**총 소요: A만 4–6일, B 포함 5–7일.**

## 5. 리스크 / 함정 (요지)

1. **재시도-금지 원장**: sunlit이 막히면 "V를 더 올리는" 우회(이진-부호·해상도·시간-평균·E-마치
   밴드)로 손이 가기 쉽다 — 전부 F6I §0 기각 계열. 재캘리브 3종+PP 밖은 wrap-up이 아니라 새
   페이즈. in-TAAU 클램프, F6N occ_soft 재도입, gi_importance도 동일 금지.
2. **게이트 없는 기본-플립 금지**(P_SDF_OPEN_UNSIGNED·ANTIFLICKER 선례): SHA 골든은 변화
   감지만 하지 개선/회귀 판정을 못 한다. 판정 불가면 옵트인 봉인이 유일한 정직한 착지.
3. **two-master 상쇄-착지**: tint/sky_gain은 디퍼드(픽셀 V)와 캐시·반사(볼륨 V)를 동시에
   섬긴다 — §3 A1의 크롭 섀도 지표 + EV11 항별 오라클 귀속 규칙 준수.
4. **sky_gain = 레퍼런스-측 변경**: PT도 소비하는 단일소스 — 변경 시 `--pt-refresh` 필수이고,
   예산이 이동하면 F6M 선례대로 사유 문서화가 필수(래칫 규율과 동일).
5. **캡처 레시피**: 같은-설정 쌍(AUTO_EXPOSURE=1·RS=1·WARMUP 192) 엄수, 매니페스트 수기편집
   금지, rt-compare 출력 형식 변경 금지, DEBUG_VIEW=10은 albedo-가중 판독 함정(raw E는 뷰 15).
6. **범위 크리프 = 최대 리스크**: 이 계획의 실질 결정은 하나(증분2 판정)로 수렴한다. 결과가
   어느 쪽이든 판정을 기록하고 닫는 것이 마무리다 — "조금만 더"가 확률적-점유의 첫 삽이 되는
   순간 wrap-up은 실패한다.
